IVC Personal Desktop · Windows 10/11 x64

1. ZIP 파일을 모두 압축 해제하고 폴더 안의 IVC.exe를 실행하세요.
   ZIP 미리보기 안에서 exe 파일만 실행하지 마세요.
2. 처음 한 번, 이 컴퓨터에서 사용할 이메일과 비밀번호를 설정합니다.
   웹사이트의 계정/비밀번호를 자동으로 가져오는 방식이 아닙니다.
3. 로그인 후 모든 계산기를 개인용 앱 창에서 사용합니다.
4. 창을 닫거나 IVC 메뉴에서 종료하면 계산 서버도 함께 종료됩니다.
5. IVC 메뉴의 '바탕 화면 바로가기 만들기'를 누르면 이후 아이콘으로 켤 수 있습니다.

Codespaces, GitHub 로그인, Node.js 설치, 터미널 명령어는 실행할 때 필요 없습니다.
이 앱은 이 컴퓨터의 127.0.0.1에서만 작동하며 다른 사람에게 공개하는 서버가 아닙니다.

데이터 위치: %LOCALAPPDATA%\IVC\Desktop
업데이트: 앱을 종료하고 새 ZIP을 새 폴더에 모두 푼 뒤 IVC.exe를 실행합니다.
계정과 모델은 위 개인 데이터 폴더에 남습니다. 폴더 이동 후에는 바로가기를 다시 만드세요.

기존 웹사이트의 모델을 옮기려면 웹사이트에서 Save Project로 JSON을 저장한 뒤
이 앱의 Import로 불러오세요. 웹사이트 계정 DB를 복사하거나 비밀번호를 전달할 필요가 없습니다.

Microsoft Edge WebView2 Runtime과 .NET Framework 4.8 이상이 필요합니다.
Windows 11에는 보통 설치되어 있습니다. WebView2가 없으면 앱이 Microsoft 공식 설치 페이지를 안내합니다.
로그인 세션은 기존과 같이 최대 30일, 7일 미사용 시 종료됩니다.

자세한 설명: 함께 들어 있는 DESKTOP_APP.md
