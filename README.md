# Polymath Studio — Equation Solver

공학 수식을 직접 입력하고 파라미터를 움직이며 해의 변화를 탐색하는 브라우저 계산기입니다. **Equation Solver** 카테고리 안에 **Linear**와 **Nonlinear**를 제공합니다. Differential Equation Solver는 이후 확장할 별도 카테고리이며 아직 실행할 수 없습니다.

## 실행하기

Node.js 22 이상과 npm을 권장합니다. 저장소 디렉터리에서 실행하세요.

```sh
npm ci
npm run build:wasm
npm run dev
```

Vite가 표시하는 주소로 접속합니다. Codespaces에서는 실행 중인 서버를 `Ctrl+C`로 종료하고 업데이트하세요. `npm run dev`가 실행 중인 터미널은 서버 입력을 받으므로, Git 명령은 서버를 중단하거나 새 터미널에서 입력합니다.

```sh
 git pull --ff-only origin codex/leq-studio
 npm ci
 npm run dev -- --port 5173 --strictPort
```

Git이 로컬 변경 때문에 업데이트를 중단하면 해당 변경을 보관한 뒤 업데이트해야 합니다. 배포용 정적 파일은 `npm run build`로 `dist/`에 생성하고 `npm run preview`로 확인합니다. `build`는 WASM 재컴파일, TypeScript 검사, Vite 빌드를 포함합니다. 별도 Python·백엔드·API 키는 필요하지 않습니다.

## 계산기 구성과 저장

- 첫 화면은 모듈 카드만 보여 줍니다. **Equation Solver**를 열면 방정식 계산기로 들어가며, 나머지 모듈은 준비 중으로 표시합니다.
- **수식·파라미터**, **시뮬레이션**, **해석 리포트**는 각각 별도 화면입니다. 상단 화면 이동 버튼으로 전환하며 작성한 모델과 선택한 해는 유지합니다. **모듈 홈**으로 돌아가도 현재 작업을 삭제하지 않습니다.
- **Linear**는 예제 없이 빈 모델에서 시작합니다. 한 줄에 하나의 방정식을 입력합니다.
- **Nonlinear**도 빈 모델에서 시작하며 **예제 불러오기**로 대표 모델 6개를 선택할 수 있습니다.
- **새 모델**은 현재 유형의 빈 모델을 엽니다. 알림의 **되돌리기**로 직전 모델을 복원할 수 있습니다.
- Linear/Nonlinear는 각각의 작업 초안을 유지합니다. 탭을 바꾸어도 작성한 수식과 파라미터를 보존합니다.
- 기존 버전의 프로젝트 JSON과 로컬 저장 내용도 불러올 수 있습니다. 유형(`mode`)이 없는 기존 파일은 Linear로 해석합니다. 기존 사용자 모델은 업데이트 시 삭제하지 않습니다.

현재 모델과 유형별 초안은 브라우저 `localStorage`에 저장됩니다. 조작 중 저장을 반복하지 않도록 300ms 유휴 후 묶어 저장하며, 페이지 숨김·종료 때 남은 변경을 저장합니다. **프로젝트 저장**은 JSON을 내려받고 **불러오기**는 JSON을 검증해 복원합니다. Nonlinear 파일에는 `mode: "nonlinear"`가 포함됩니다. 예제를 불러오면 현재 모델을 교체하므로 보관할 모델은 JSON으로 저장하세요. 저장소 접근이 차단되어 있으면 자동 저장 불가 상태를 표시합니다.

## 새 함수 문법과 병합 시뮬레이션

`f1(x)=2x+4`, `f2(x)=-3x+7`을 정의한 다음 `f1(x)-f2(x)=0`처럼 연산한 방정식을 풉니다. 여러 미지수를 섞는 식은 `f1=2x+y-10`처럼 정의합니다. 파라미터는 연속 조절하며 **샘플 포인트 간격**은 표와 그래프의 마커에 적용합니다. **시뮬레이션 병합 세트 추가**로 여러 해를 한 그래프에 비교하고 세트별로 포함할 해를 선택합니다.

[사용법·첨부 코드 검토·남은 한계](docs/V2_INTEGRATION.md)를 참고하세요. 병합·소멸 표시는 수치 추정이며, 추적 불가는 실근 부재의 증명이 아닙니다.

## Linear 사용법

숫자·미지수와 `+ - *`로 선형식을 작성합니다. `2x`, `2 x`, `2*x`는 같은 뜻입니다. 선형성을 유지하는 괄호와 알려진 값으로의 나눗셈도 지원합니다. `#` 뒤는 주석입니다.

`2(x+1)`과 `(x+1)k`도 곱셈으로 읽습니다. 이름 바로 뒤의 괄호는 함수와 혼동하지 않도록 `x*(y+1)`처럼 `*`를 적습니다. 선형식의 `e`, `pi`는 기존 모델과의 호환성을 위해 변수·파라미터 이름으로 유지합니다. 거듭제곱은 단항 음수보다 먼저 계산하므로 `-2^2=-4`, `(-2)^2=4`입니다.

```text
2x + y = 10
x - y = 2
```

미지수는 계산으로 구할 값입니다. 파라미터 패널에 등록한 이름은 알려진 값으로 취급합니다. 예를 들어 `x + y = F`에서 F를 파라미터에 등록하면 x와 y만 미지수입니다. 수식에 `F = 100`을 입력하면 그 줄도 방정식 하나로 처리합니다.

방정식 수와 미지수 수가 같아야 하고, 유일해를 얻으려면 식들이 독립적이어야 합니다. `x*y`, `x^2`, `sin(x)` 같은 비선형식은 Nonlinear로 작성해야 합니다. 이름은 영문자로 시작하며 영문·숫자·밑줄을 사용하고 대소문자를 구분합니다. 소수점은 `.`이며 과학적 표기 `1.2e-3`도 사용할 수 있습니다. Linear는 최대 64개 미지수를 지원합니다.

## Nonlinear 사용법: 식만 입력하고 여러 실수 해 비교하기

기본값은 **자동 실수 해 탐색**입니다. 초기 추정값이나 min/max를 입력할 필요 없이, 일반 등식을 그대로 적습니다.

```text
x^2 = 4
```

발견한 실수 해 2와 -2를 함께 표시합니다. 해는 원점(0)에 가까운 순서이며, 같은 거리에서는 양수 해가 먼저 나옵니다. **해 목록**에서 하나를 선택하면 해당 해의 값·국소 조건수·리포트와 파라미터 시뮬레이션으로 전환됩니다. **리포트 저장**은 선택한 해를, **모든 해 리포트 저장**은 현재 발견한 각 해를 개별 절로 담은 Markdown 파일을 내려받습니다. CSV도 선택한 해의 가지에 대한 데이터이며 파일명에 해 번호가 포함됩니다.

연립식도 한 줄에 등식 하나씩 작성합니다.

```text
x^2 + y^2 = 25
x - y = 1
```

여러 시작점을 자동으로 시도해 (-3,-4)와 (4,3)을 발견합니다. 일반 등식에서 `y = 2`는 보조식 대입문이 아니라 풀어야 할 조건입니다. 미지수 수와 독립적인 식 수를 맞추세요. 조절할 상수는 파라미터 패널에 등록합니다.

### 자동 탐색 범위와 수치적 한계

지원되는 단일 다항식은 계수로부터 잡은 범위에서 도함수의 임계점을 이용해 실근을 수치적으로 분리합니다. 부호가 바뀌지 않는 반복근도 찾도록 처리합니다. 일반 함수와 연립식은 기본 -100~100 영역에서 구간 분할과 여러 초기점을 사용합니다. **실제로 사용한 범위·방법·누락 가능성은 결과에 표시**합니다. 필요하면 **고급 탐색 설정**에서 선택적으로 범위를 바꿀 수 있습니다.

일반 비선형식의 모든 해를 찾았다는 보장은 하지 않습니다. `sin(x)=0`처럼 실근이 무한히 많은 식도 있으며, 좁은 수렴 영역·매우 가까운 근·수치 오차로 일부 해가 누락될 수 있습니다. 해가 많거나 주기적으로 무한히 반복되는 경우에도 원점에서 가까운 곳부터 탐색하고, 발견한 해 중 0에 가까운 최대 32개를 표시합니다. 연립식의 거리는 각 변수 값으로 구성된 벡터의 Euclidean 거리 기준입니다. 이는 사용한 변수 단위에 영향을 받습니다. 탐색 시간 또는 표시 개수 제한에 도달하면 안내합니다. 해가 발견되지 않았다는 결과도 실수 해가 전혀 없다는 수학적 증명은 아닙니다. 복소수 해는 이번 범위에 포함하지 않으며 이후 별도 계산기로 분리할 예정입니다.

### 보조식과 함수

함수를 정의하고 일반 등식으로 목표값을 지정합니다.

```text
f1(x) = x*log(x/2) + 4*x^2
f1(x) = 1620
```

`log`/`log10`은 상용로그, `ln`은 자연로그입니다. `sin`, `cos`, `tan`, `exp`, `sqrt`, `abs`, `pi`, `e` 등을 지원하며 삼각함수는 라디안 기준입니다. 명시식은 입력 순서에 관계없이 의존 관계를 검증하며, 중복 정의·순환 참조·정의되지 않은 이름·실수 정의역 오류를 거부합니다. `eval`을 사용하지 않습니다.

함수 호출은 `SIN(x)`, `Log10(x)`처럼 대소문자를 섞어도 됩니다. 변수 이름의 대소문자는 계속 구분합니다.

### 고급 옵션: 초기 조건으로 한 해 찾기

필요할 때만 **고급 탐색 설정 → 해 탐색 방식 → 초기 조건으로 한 해 찾기**를 선택합니다. 이 모드도 같은 등식 문법을 사용하며 초기값 또는 탐색 범위를 추가합니다.

```text
# 단일근: 탐색 구간으로 한 근 선택
x^2 = 4
x(min) = 0
x(max) = 3
```

```text
# 연립식: 각 미지수의 초기 추정값
x^2 + y^2 = 25
x - y = 1
x(0) = 4
y(0) = 3
```

명시식만 계산하는 NLE0도 이 고급 모드에서 사용합니다. 자동 모드에서는 수식에 남아 있는 `(min)/(max)/(0)` 대신 자동 탐색 설정을 사용하며, 화면에 이 차이를 안내합니다. 기존 조건을 유지하려면 수동 모드로 바꾸세요. `#@` 해법 지시문과 부등식 제약은 지원하지 않고 오류로 안내합니다.

## 여러 해의 동시 시뮬레이션

해 카드의 **시뮬레이션 추가**를 누르면 해당 해를 기준으로 독립적인 창을 엽니다. 최대 6개를 동시에 비교하고 각 창을 개별적으로 닫을 수 있습니다. 창마다 그래프·표 선택, 표시할 변수, CSV·리포트 저장이 분리됩니다. 추가한 시점의 변수·파라미터를 기준값으로 보관하므로, 이후 해 목록 순서가 바뀌어도 단순한 목록 번호로 다른 가지를 선택하지 않습니다.

**파라미터 범위·간격은 수식·파라미터 화면**에서 설정합니다. **실제 값 입력과 슬라이더는 시뮬레이션 화면**에 있으며 열린 모든 창에 함께 적용됩니다. 결과 탐색 확대 버튼은 전체 화면 작업 영역을 열고 그래프 자체의 높이·폭도 키웁니다. 전체 화면에서도 파라미터 값을 조절할 수 있으며, Escape 또는 기본 레이아웃 버튼으로 돌아옵니다.

각 창은 추가한 시점의 기준 해를 보관합니다. **같은 해와 범위에서 탐색 변수만 움직이면 기준 곡선은 유지하고 현재 지점만 옮깁니다.** 탐색 변수 이외의 고정 파라미터, 선택한 해 또는 범위가 바뀌면 곡선을 다시 계산할 수 있습니다. 이 기능은 교차점·분기점에서 가지의 수학적 동일성을 증명하지는 않습니다. 추적에 실패하면 현재 해에 오류를 표시합니다. 현재 탐색 변수 값에서 해가 사라져도 검증한 기준점에서 계산할 수 있는 곡선 구간은 남기며, 실패한 구간은 빈 값으로 표시합니다.

### 주기 함수의 그래프와 해 존재 범위

`sin(x)*cos(x)=target`은 `0.5*sin(2*x)=target`과 같으므로 실수 해가 존재하는 target 범위는 **-0.5~0.5**입니다. 0.5 이후에 곡선이 끊기는 것은 정상이며, 빈 구간을 선으로 이어 그리지 않습니다. 큰 |x|의 작은 변화가 평평하게 보이지 않도록 Y축을 0에 강제로 맞추지 않고 실제 표시 데이터에 맞춥니다.

추적기는 파라미터 간격을 필요에 따라 나누고, 보정량과 역방향 복귀를 검증해 다른 주기로의 갑작스러운 이동을 감지합니다. 정적 탐색 결과, 현재 해와 그래프의 데이터 지점은 분리하여 검토합니다. 해가 합쳐지는 지점·정의역 경계·극점에서 모든 가지를 유지한다는 보장은 없습니다.

## 시뮬레이션과 리포트

수식이나 파라미터를 수정하면 자동으로 계산합니다. 자동 모드의 현재 탐색 결과는 해 선택 시 재사용합니다. **모델 풀기** 또는 `Ctrl/Cmd+Enter`로 다시 계산할 수도 있습니다. 결과 탐색의 파라미터 숫자 입력란은 Enter 또는 포커스 이동 시 적용하며, 슬라이더는 즉시 반영됩니다.

수식 입력은 160ms, 값 조작은 16ms 동안 모아서 워커에 전달합니다. 호환되는 탐색 변수 조작에서는 선택한 해의 현재값을 먼저 표시하고, 180ms 동안 새 조작이 없으면 전체 해 목록을 갱신합니다. 이때 화면에 갱신 상태를 표시하며 이전 파라미터의 해 목록을 현재 결과로 재사용하지 않습니다.

그래프는 별도 렌더링 지점으로 곡선을 그리고, **표와 CSV는 설정한 파라미터 간격**을 따릅니다. 예를 들어 `0.2~0.8`, 간격 `0.01`이면 61행입니다. 최댓값이 나누어떨어지지 않으면 마지막 행에 최댓값을 한 번 포함하고 마지막 구간이 짧다는 안내를 표시합니다. 마우스를 움직이면 표시한 곡선을 따라 탐색 점이 부드럽게 이동하고 표에서는 가까운 행을 표시합니다. 이 탐색 표시의 보간값은 새로 계산한 해와 구분합니다. **그래프를 클릭하면 해당 가로축 값이 실제 파라미터로 적용되어 다시 계산**되며, 마우스를 치워도 선택한 현재값은 유지합니다.

그래프를 클릭하여 활성화한 뒤 휠을 움직이면 축의 표시 비율을 점진적으로 확대·축소합니다. **그래프 확대 축**에서 양축·X축·Y축을 고르고 **축 초기화**로 원래 범위를 복원합니다. 축 조정은 해를 다시 계산하거나 원래 데이터 표를 바꾸지 않습니다. 활성화하지 않은 그래프 위에서는 일반 페이지 스크롤을 유지합니다. 키보드로는 좌우/Home/End로 표의 지점을 탐색하고 Enter/Space로 값을 적용하며, `+`/`-`로 축 확대·축소, `0`으로 초기화합니다.

표·CSV는 Linear 최대 2,000행, Nonlinear 최대 500행입니다. 초과 시 간격을 임의로 바꾸지 않고 조정 안내를 표시하며, 현재 해와 그래프는 유지합니다. 자동 모드의 시뮬레이션은 선택한 해에서 양방향으로 수치적 연속 추적을 수행합니다. 가지가 사라지거나 추적이 실패하면 빈 결과로 남기고 다른 가지로 임의 전환하지 않습니다. 분기점·교차점에서는 같은 가지를 유지한다고 보장할 수 없으며, 끊어진 가지를 건너뛰어 다시 연결하지 않습니다. 고급 수동 모드는 동일한 초기값·구간으로 각 지점을 풉니다. 실패한 지점은 `해 없음`과 빈 CSV 결과로 남깁니다. 그래프는 시간에 따른 미분방정식 적분이 아닙니다.

리포트는 Markdown, 계산 데이터는 CSV로 저장합니다. Linear의 계수 행렬과 Nonlinear 수렴점의 Jacobian은 리포트의 접기/펼치기 상세 영역에서 검토합니다. 비선형 리포트는 계산 방법·반복 횟수·등식 오차·보조식 결과를 제공합니다.

## 조건수와 민감도

리포트에서 기존 **∞-norm** 또는 **2-norm(SVD)** 을 선택합니다. `κ∞(A)=||A||∞·||A⁻¹||∞`, `κ₂(A)=σmax/σmin`이며 2-norm은 `ml-matrix`의 직접 SVD로 계산합니다. `AᵀA`를 만드는 방식은 사용하지 않습니다. 선택은 프로젝트 JSON·자동 저장·리포트에 반영됩니다.

| 조건수 κ         | 참고 표시        |
| ---------------- | ---------------- |
| 1 ≤ κ < 10⁴      | 초록 · 안정      |
| 10⁴ ≤ κ < 10⁸    | 노랑 · 민감      |
| κ ≥ 10⁸ (∞ 포함) | 주황 · 매우 민감 |
| 계산 실패        | 회색 · 판정 불가 |

Linear는 행별 정규화 전의 원래 계수 행렬 A를, Nonlinear는 해 주변의 수치 Jacobian J를 진단합니다. 비선형 조건수는 국소 정보이며 전역 수렴이나 유일성을 보장하지 않습니다. 특히 1×1의 비영 Jacobian은 행렬 조건수가 1이므로, 단일근의 실제 민감도는 도함수 크기·측정 오차와 함께 봐야 합니다. 색상은 참고 범위이며 단위·스케일·입력 정밀도에 따라 해석해야 합니다. 작은 등식 오차도 정확한 해를 보장하지 않습니다. 2-norm 선택 자체가 해 계산의 정밀도를 높이지는 않습니다.

## 아키텍처와 검증

React·TypeScript UI → 안전한 AST 파싱/캐시 → Web Worker 수치해석 → 반응형 그래프·표·리포트로 구성합니다.

- `src/engine/index.ts`: Linear 파서와 부분 피벗팅 가우스 소거법. `solver.wat`를 `wabt`로 컴파일한 WASM을 사용합니다.
- `src/engine/nonlinear-parser.ts`: 일반 등식·함수 정의·구간/초기값과 함수의 안전한 파서 및 의존 관계 검증.
- `src/engine/automatic.ts`, `automatic-polynomial.ts`: 일반 등식 정규화, 단일 다항식 실근 분리, 구간 분할·다중 시작점 탐색과 중복 제거.
- `src/engine/branches.ts`: 기준 해의 연속 추적, 국소 보정·역방향 검증과 실패 구간 처리.
- `src/engine/simulation-panels.ts`: 독립 기준 해 스냅샷과 창별 계산 캐시.
- `src/components/SimulationPanelView.tsx`: 창별 그래프·표·CSV·리포트와 닫기.
- `src/components/chart-domain.ts`: 실제 데이터에 맞춘 축 범위 및 극단값 처리.
- `src/engine/nonlinear.ts`: 단일근 구간 이분법과 명시식 평가는 JavaScript, 연립 Newton 보정은 실제 WASM 선형 커널을 사용합니다. WASM을 사용할 수 없는 경우에는 표시된 JavaScript 대체 경로를 사용합니다.
- `src/engine/conditioning.ts`: 원래 A 또는 수렴점 J의 ∞/2-norm 조건수와 민감도 분류.
- `src/engine/sweep.ts`: 그래프와 표의 계산 지점 분리 및 누적 오차 없는 간격 처리.

## 핵심 코드 직접 읽기

실제 실행 소스를 세 개의 Markdown 파일로 묶었습니다. 설명만 요약한 문서가 아니라 **수식 파서·수치해석·상태 관리·그래프·애니메이션의 원본 코드 전체**를 파일 경계와 함께 제공합니다.

1. [수식 파싱과 수치해석 엔진](docs/core-code/01-math-engine.md): Linear/NLE 파서, 실근 자동 탐색, 다항식 실근 분리, 조건수, WebAssembly 커널과 빌드.
2. [상태 관리와 시뮬레이션](docs/core-code/02-state-and-simulation.md): 파라미터 간격, 기준 해 추적, 해별 캐시, Web Worker, React 상태와 저장·리포트 연결.
3. [그래프와 마우스 조작](docs/core-code/03-chart-and-interaction.md): 좌표·보간·축 조정, SVG 렌더링, 다중 그래프, 화면 이동, CSS 전환·애니메이션.

GitHub에서 문서를 열면 코드 블록을 바로 볼 수 있습니다. 파일 상단의 **Raw** 또는 **Download raw file**로 `.md` 원문도 저장할 수 있습니다. 각 묶음은 읽기용 복사본이며 import 경로는 원래 저장소 구조를 따릅니다. 코드를 실행하려면 저장소의 원본 파일을 사용하세요.

```sh
npm run docs:core
npm run docs:core -- --check
```

첫 명령은 현재 소스로 세 문서를 다시 만들고, 두 번째 명령은 소스와 문서가 일치하는지 검사합니다. 생성 시각을 넣지 않아 동일한 소스는 동일한 문서를 만들며, 파일별 SHA-256도 함께 표시합니다.

## 검증 명령

```sh
npm test
npm run build
npm run test:e2e
```

수치·파서·실제 WASM 회귀 테스트와 Chromium 사용자 흐름을 검증합니다. 브라우저 테스트는 시스템 `/usr/bin/chromium` 또는 Playwright Chromium을 사용합니다. 필요하면 `npx playwright install chromium` 또는 `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH`를 설정합니다.

계산과 저장은 브라우저에서 수행하며 모델을 외부 서버로 보내지 않습니다. 앱·WASM 로드 후 현재 페이지는 네트워크 없이 계산할 수 있지만, 오프라인 새로고침/PWA·클라우드 계정 동기화·단위 자동 검증·최적화·ODE는 구현하지 않았습니다. 로컬 저장은 암호화된 비밀 저장소가 아닙니다.

접점 차수 진단, 정의역 경계 처리, 함수·문법 공식집의 적용 범위는 [V3 통합 기록](docs/V3_INTEGRATION.md)을 참고하세요.

공식집의 화면 수정과 새 과학 예제 8개의 사용 순서는 [수학·과학 예제 안내](docs/SCIENTIFIC_EXAMPLES.md)에 정리했습니다. 해당 문서는 전체 모델의 참고 자료이며, 현재 메뉴에는 대표 6개만 표시합니다.

다중·연쇄 등식, 단위 주석, 유리식 근 탐색과 자동미분의 적용·검증 결과는 [계산 안정화 검토](docs/CALCULATION_AUDIT.md)에 정리했습니다. 예제 메뉴의 **몰체적을 계산하는 van der Waals**에서 280 K·53 bar의 세 근을 확인할 수 있습니다.

고급 탐색 설정의 변수별 범위·이동 가능한 탐색 창, 고차 중근과 비매끄러운 식 처리는 [유한 탐색 검토](docs/BOUNDED_SEARCH.md)에 정리했습니다.

**고급 탐색 설정 → 구간 검증 사용**은 단일 변수 식의 실제 탐색 범위를 추가 검증합니다. 유일근 구간·해 부재·미결정 구간을 구분하며, 포획 확률은 산출하지 않습니다. 사용법과 첨부 코드의 보정 근거는 [구간 검증 통합 기록](docs/INTERVAL_CERTIFICATION.md)에 있습니다.

일반 등식의 수동 초기값·범위 설정, 이전 저장 모델 전환, 중복 없는 근 병합 안내는 [입력·이벤트 정리](docs/EQUATION_INPUT_AND_EVENTS.md)를 참고하세요.

리포트의 오차 상한·민감도 시나리오·검증률, 2~8중근 기호와 스크롤 수정은 [리포트·근 표시 안내](docs/REPORT_AND_ROOT_TYPES.md)를 참고하세요.
