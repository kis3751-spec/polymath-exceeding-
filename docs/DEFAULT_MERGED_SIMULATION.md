# 기본 병합 시뮬레이션

Nonlinear 자동 탐색에서는 병합 세트를 수동으로 만들기 전부터 **전체 해 탐색** 그래프를 표시합니다. 현재 파라미터의 근 외에, 설정 범위의 중앙·양 끝·사분점에서도 후보 근을 찾고 서로 다른 가지의 기준점으로 사용합니다. 현재 실근이 하나뿐이거나 없더라도 범위의 다른 지점에서 발견한 가지를 표시할 수 있습니다.

- 기본 그래프는 최대 6개 가지를 비교합니다. 초기 추가 탐색에는 지점 사이에서 검사하는 시간 예산이 있으며, 범위의 모든 해를 증명하는 전역 분기 탐색은 아닙니다.
- 초기 표본 사이의 좁은 구간에서 나중에 해를 발견하면 기존 곡선을 교체하지 않고 새 기준 가지를 추가합니다. 현재 파라미터만 바꾸면 기존 곡선 배열은 유지하고 현재 해만 다시 계산합니다.
- 범위·고정 파라미터·수식·탐색 경계가 바뀌면 해당 조건의 기본 그래프를 다시 준비합니다. 초기 해 집합과 곡선은 Worker 안에서 캐시합니다.
- 색상별 해 버튼으로 포함·제외하며, **각 해 결과·선택**을 펼쳐 해를 선택하거나 해당 리포트로 이동합니다. 선택한 해는 카드 테두리로 구분합니다.
- 기본 그래프를 닫아도 **기본 병합 보기**로 다시 열 수 있습니다. 별도 병합 세트와 개별 시뮬레이션 추가 기능도 유지합니다.
- 기본 그래프의 일시적 표시 선택은 세션 UI 상태입니다. 기존 사용자 병합 세트와 개별 시뮬레이션은 프로젝트 저장 형식을 계속 사용합니다.

시뮬레이션 화면에서 로고·분류 경로·소개 제목과 설명·상단 프로젝트 작업 버튼을 숨겼습니다. 화면 이동, 파라미터 조절, 해 선택과 추가 병합 등 작업 도구를 남기며, 기본 그래프는 가용 폭과 화면 높이에 맞춰 크게 그립니다. 프로젝트 저장·불러오기는 수식·파라미터 화면과 리포트 화면에서 이용합니다.

검증: 수치·상태 회귀 488개와 배포 빌드 통과. 새 브라우저 검사는 초기 1개 실근에서 3가지 준비, 현재 실근 부재에서 2가지 준비, 파라미터 이동 시 곡선 불변성, 개별 선택·리포트, 넓은 그래프와 모바일 배치를 확인합니다. 기존의 수동 병합을 전제로 하는 화면 선택자 전체를 이 새 화면의 검증으로 간주하지 않습니다.

최종 배포 빌드의 새 브라우저 시나리오 3개가 모두 통과했습니다. 수치 회귀 488개·타입 및 빌드·형식 검사·핵심 코드 문서 일치 검사도 통과했습니다.
