# IVC Personal Desktop · Windows

이 버전은 Windows 10/11 x64에서 개인용 프로그램으로 실행합니다. ZIP을 모두 푼 뒤 `IVC.exe`를 더블클릭합니다. 실행할 때 Codespaces·GitHub 로그인·Node.js 설치·npm 명령·포트 공개 설정이 필요하지 않습니다. `.exe`·DLL·runtime·app 폴더를 함께 보관합니다.

GitHub → Actions → **Build IVC Windows App** → 성공한 실행 → **Artifacts**에서 ZIP을 내려받습니다. Artifact 링크는 보관 기간이 지나면 만료되지만 다운로드한 프로그램은 계속 사용할 수 있습니다. 새 빌드는 Run workflow로 만듭니다. 이 빌드의 실행 파일은 아직 코드 서명하지 않았습니다.

## 처음 한 번

이 PC용 계정을 만들고 로그인합니다. 기존 공유 사이트 계정과 별개이며 비밀번호는 scrypt 해시로 저장합니다. 첫 계정은 앱이 소유한 표준 입력 파이프로만 설정하고 HTTP 초기화 API를 열지 않습니다. 계정이 이미 있으면 덮어쓰지 않습니다. 로그인 쿠키·프로젝트 자동 저장은 별도의 WebView2 사용자 프로필에 보관합니다. 기존 세션 정책인 최대 30일·7일 미사용 종료를 유지하므로 만료 후에는 로그인해야 합니다.

다음 실행부터 유효한 로그인 쿠키가 있으면 계산기 화면으로 바로 들어갑니다. 세션이 만료되었으면 기존 서버의 인증 검사가 로그인 화면으로 이동시킵니다.

IVC 메뉴의 **바탕 화면 바로가기 만들기**를 누르면 다음부터 바탕 화면 아이콘으로 실행합니다. 중복 실행은 기존 창을 앞으로 가져옵니다. 창의 X 또는 IVC → 종료를 누르면 저장 이벤트를 보낸 뒤 앱이 시작한 계산 프로세스를 종료합니다. 다른 Node 프로세스나 임의의 포트 사용 프로그램을 종료하지 않습니다. 부모 앱이 비정상 종료되어 입력 파이프가 닫혀도 계산 프로세스는 종료합니다.

## 데이터와 업데이트

- `%LOCALAPPDATA%\IVC\Desktop\Data`: 개인 계정과 세션 DB.
- `%LOCALAPPDATA%\IVC\Desktop\Browser`: 해당 계정의 계산 모델·설정과 로그인 쿠키를 보관하는 WebView2 프로필.
- 새 ZIP을 다른 폴더에 풀어 실행해도 개인 데이터 경로와 원점은 동일합니다. 앱 폴더를 옮기면 바로가기를 다시 만듭니다.
- 기존 웹사이트에서는 Save Project로 JSON을 내보낸 뒤 앱에서 Import합니다. 서버 DB와 웹사이트 localStorage를 자동으로 가져오지 않습니다.
- 백업은 앱을 닫은 상태에서 위 Desktop 폴더 전체를 복사합니다. 계정 DB와 브라우저 프로필은 개인 파일이므로 앱 배포 ZIP이나 Git에 포함하지 않습니다.

앱을 업데이트하려면 종료 후 새 ZIP을 모두 압축 해제하고 새 `IVC.exe`를 실행합니다. 매번 Git pull·npm 설치·빌드를 수행하지 않습니다. 이 앱은 자동 업데이트를 설치하거나 Windows 시작 프로그램에 등록하지 않습니다.

## 실행 경계

계산기는 기존 UI·Worker·수식 엔진을 사용하며 ODE·회귀 잔차·차수 비교·적분·최적화 등을 동일하게 제공합니다. 내장 Node.js가 **127.0.0.1:53173**에서만 수신합니다. 배포용 HOST·APP_ORIGIN·Codespaces 환경변수로 외부 공개 서버로 바뀌지 않습니다. 포트가 다른 프로그램에 사용 중이면 원점을 임의로 바꾸어 저장 모델을 잃게 하지 않고 오류를 표시합니다.

계산 파일은 기존 로그인·Host·Origin·CSRF·권한 검사로 보호됩니다. WebView2의 최상위 탐색은 해당 원점으로 제한하며 사용자 클릭의 HTTP/HTTPS 외부 링크만 기본 브라우저로 엽니다. 파일·실행 코드 URL을 실행하지 않습니다. 개인용 설치는 Windows 사용자 계정의 파일 접근 권한에 의존하며, 해당 Windows 계정이나 컴퓨터가 침해된 경우까지 보호하는 비밀 저장소는 아닙니다.

Microsoft Edge WebView2 Runtime과 .NET Framework 4.8 이상이 필요합니다. Windows 11에는 일반적으로 갖춰져 있습니다. WebView2 미설치 시 앱에서 Microsoft 공식 설치 페이지로 안내합니다. 앱 창을 닫으면 실행이 중단되므로 다른 사람에게 상시 접속 주소를 제공하는 용도로는 사용하지 않습니다.

## 배포 패키지 만들기

개발·배포용 PC에서 Node 24와 .NET SDK를 설치한 뒤 실행합니다. 일반 사용자에게 필요한 명령은 아닙니다.

```sh
npm ci
npm run desktop:package
```

`release/IVC-Desktop-Windows-x64.zip`과 SHA-256 파일을 생성합니다. 공식 Node.js Windows ZIP의 SHA-256을 확인한 뒤 런타임과 라이선스를 포함합니다. WebView2 SDK 버전과 NuGet 잠금 파일을 고정하며 SDK 라이선스를 동봉합니다. 실제 계정 DB·비밀번호·사용자 프로필·.env는 포함하지 않습니다. 패키지 내부 manifest.json에는 파일별 SHA-256을 기록합니다.

Linux에서 교차 빌드할 때는 .NET SDK의 경로를 `IVC_DOTNET`으로, 다운로드 캐시를 `IVC_PACKAGE_CACHE`로 지정할 수 있습니다. Windows 실행 파일의 빌드 성공과 실제 Windows PC에서의 창·WebView2 실행 검증은 별개입니다.

## 검증 범위

Windows x64 GUI 실행 파일의 교차 빌드는 경고·오류 없이 완료했습니다. 개인용 서버·패키지 검사 7개와 기존 인증 검사 79개를 통과했고, ZIP에 실제 포함된 서버·계산기 파일을 Chromium에서 실행해 15개 사용자 흐름을 확인했습니다. 첫 설정의 비밀번호 원문 미출력, 기존 계정 덮어쓰기 거부, 재시작 후 세션 복원, 외부 Origin 차단, 포트 충돌 시 다른 프로그램 보존과 부모 입력 파이프 종료 시 서버 종료를 포함합니다. 파일별 SHA-256·x64 실행 파일·필수 파일·개인 데이터 제외도 검사합니다.

GitHub Windows 환경의 [빌드·서버·실제 앱 시작 및 종료 검사](https://github.com/kis3751-spec/polymath-exceeding-/actions/runs/43173540003)가 통과했습니다. 네이티브 앱 창과 자체 Node 프로세스를 실제로 시작하고, 창을 닫으면 두 프로세스가 모두 종료되는지 확인했습니다. 이 실행의 Artifact는 ZIP을 한 번 풀면 IVC.exe가 나오는 구조입니다. 파일 선택 대화상자·바탕 화면 바로가기·실제 WebView2 계산기 내부 조작까지 모두 자동화한 GUI 검사는 아닙니다. 계산기 내부의 동작은 패키지 파일을 사용한 Chromium 시나리오로 별도 확인합니다.
