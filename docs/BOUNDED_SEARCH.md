# 유한 탐색 창·변수별 범위·고차 중근 처리

첨부 `polymath_bounded_search_v3_patch.md`의 방향을 현재 엔진에 맞춰 통합했습니다. 기존 유리식 분자 추출·원래 식 대입 검증·파라미터 경로 가드는 유지합니다. 이번 변경은 모든 방정식에 대한 완전 탐색 증명이 아닙니다.

## 탐색 창

고급 탐색 설정에 **탐색 창 중심**과 **탐색 창 이동**을 추가했습니다. 현재 창·최대 폭은 결과의 탐색 설명에도 나옵니다. 최대 폭을 넘는 입력은 거부하며, 중심 위치를 바꿔 다른 영역을 탐색합니다. 창을 옮기면 선택 중인 자동 해를 다시 채택하고, 사용자가 별도로 고정한 시뮬레이션은 보존합니다.

### 분석 가능한 주기식

`A*sin(a*x+b)+B=0`, cos, tan처럼 단일 삼각함수에 선형 위상과 상수 배율·이동을 적용한 식은 위상을 분석합니다. 각 위상족의 정수 주기를 열거하고 후보를 원래 식에 대입합니다. 다중 조화함수의 합·곱을 이 형태라고 추측하지 않습니다.

sin/cos의 최대 폭은 `28*pi/abs(a)`로 설정해 끝점까지 포함한 표시 근 수를 32개 이내로 유지합니다. tan에도 같은 보수적 폭을 사용합니다. `sin(1000*x)=0`의 기본 창은 대략 `[-0.0439823, 0.0439823]`, 폭은 약 0.0879646이며 29개 근을 표시합니다. 중심 10으로 옮긴 창에서는 해당 위치의 근을 표시합니다. 기존 범위가 더 좁으면 넓히지 않습니다.

이는 분석한 위상의 후보를 열거하는 경로입니다. Float64 삼각함수·위상 연산의 오차는 남고, 정확한 기호적 근 인증을 뜻하지 않습니다. 위상 크기가 1e8을 넘거나 창 폭을 표현할 수 없는 위치는 안전한 분석 범위 밖으로 처리합니다. 최대 폭보다 작은 창이라고 임의의 함수의 모든 근을 보장하는 것은 아닙니다.

### 일반 함수의 관찰 기반 축소

위상 분석이 적용되지 않는 스칼라 식에서 표시 제한에 도달하면, 발견한 근의 분포를 이용해 한 번 더 좁은 창을 탐색합니다. 결과에는 **관찰 밀도 기준·완전성 보장 아님**을 표시합니다. 같은 식·파라미터의 밀도 제한은 해당 Worker 세션에서 캐시합니다. 위치가 바뀌면 같은 제한 폭을 적용하되 밀도가 다른 영역에서도 완전하다고 판단하지 않습니다. 새로고침 후 일반 함수의 관찰 기준은 다시 평가될 수 있습니다.

임의의 함수에는 유한한 관측으로 ‘모든 근을 보장하는 최대 길이’를 알아낼 수 없습니다. 해가 없는 것처럼 보이는 두 표본 사이에 임의로 많은 진동이나 접하는 근을 넣을 수 있기 때문입니다. 따라서 일반 함수에는 분석 가능한 주기식과 동일한 보장 문구를 사용하지 않습니다.

## 미지수별 범위

**고급 탐색 설정 → 미지수별 탐색 범위**에서 각 변수의 최솟값·최댓값을 적고 **범위 적용**을 누릅니다. 지정한 값은 프로젝트 JSON·자동 저장에 포함되며 Worker의 탐색 캐시 키에도 반영됩니다. 지정하지 않은 변수는 공통 범위를 따릅니다. 일반 함수의 기본 공통 범위는 −100~100입니다. 다항식·유리식의 계수 기반 자동 범위는 기존 계산기 동작을 보존합니다.

다변수 시작점은 각각의 범위로 만든 직교 상자 안에서 중심, 경계·축 투영, Halton 저불일치 수열로 구성하며 총 상한은 160개입니다. Halton 구현을 Sobol이라고 부르지 않습니다. 모든 다변수 해를 빠짐없이 찾는 보장은 아닙니다. 최종 해도 각 변수 범위 안인지 다시 확인합니다. 고정 조건 소거로 구한 변수 역시 자신의 지정 범위를 적용받습니다.

탐색 범위는 **근 발견 범위**입니다. 모델의 정의역이나 파라미터 슬라이더 범위를 바꾸지 않으며, 별도로 고정한 분기 시뮬레이션의 전체 궤적을 잘라내지 않습니다.

## 고차 중근

1. 잔차의 최상위가 양의 정수 거듭제곱 `G(x)^m=0`이면 영점 조건 `G(x)=0`으로 분리해 탐색합니다. 음의·0·분수 거듭제곱을 같은 방식으로 바꾸지 않습니다. 반환값의 잔차와 Jacobian은 원래 식에서 계산합니다.
2. 전개된 고차 다항식은 Float64 계수의 십진 표현을 정수 계수로 바꾼 뒤 BigInt 다항식 GCD로 반복 인수를 제거합니다. 차수·정수 비트 수의 한도를 두며, 한도 초과 시 원래 경로로 돌아갑니다. 제거한 계수 다항식에서도 원래 수식의 정의역·잔차 검증은 유지합니다.
3. `(x-2)^4`, 6·8·10·12차, 전개된 `(x-2)^6`, `(sin(x))^6=0`을 확인합니다. 근 근처의 작은 잔차만으로 여러 점을 별개의 근으로 만드는 방식은 사용하지 않습니다.

BigInt GCD는 **이미 계산된 계수 다항식**의 반복 인수에 대한 것입니다. 원래 수식 전개에서 이미 사라진 유효숫자를 복구하거나 모든 일반 함수의 중근을 증명하지는 않습니다. 기존의 2·3·4차 접점 분류 범위를 6차 분기 분류까지 확대했다고 표시하지 않습니다.

## 비매끄러운 식

- abs·min·max는 보통 연속이지만 꺾임점에서 미분 불가능하고, floor·ceil·sign은 점프가 있을 수 있습니다. 이들을 구분해 진단합니다.
- 비매끄러운 스칼라 자동·수동 근 탐색은 미분 없이 부호 구간 이분과 `|F|`의 국소 최소 탐색을 사용합니다. 부호 점프만으로 근을 승인하지 않습니다. 작은 양의 최솟값도 0이라고 만들지 않습니다.
- 비매끄러운 분기의 현재값 추적에도 미분 없는 국소 탐색을 쓰고, 기존 이동량·역방향 확인을 유지합니다. 접점 차수나 미분 기반 조건수는 적용하지 않고 추적 경계·수치적 가까워짐을 표시합니다.
- `floor(x)=2`처럼 0이 연속 표본에 이어지는 구간은 **구간 해 대표값**으로 표시합니다. 표본에서 관찰한 구간 해이며 모든 정확한 구간 경계를 계산했다는 뜻이 아닙니다.
- 미분 없는 비매끄러운 **다변수** 솔버는 아직 없습니다. 고정 조건으로 스칼라 문제로 줄일 수 없는 경우 지원하지 않는다고 안내하며, 조용히 Newton으로 처리하지 않습니다.

## 첨부 설명의 보정

- `[-1,1]`에 0.0025 간격이면 끝점을 포함해 **801점**입니다. 401점이 아닙니다.
- 일반 스칼라 스캔은 4096분할, 원점 주변 801점, 기존 로그 크기별 격자를 함께 사용합니다.
- ‘0.02ms’, ‘100% 포획’, ‘다차원 독립 해를 빠짐없이’라는 주장은 이번 구현의 측정·보증으로 채택하지 않았습니다. 탐색 범위·시간·차수·유한정밀도의 제한은 계속 표시합니다.
