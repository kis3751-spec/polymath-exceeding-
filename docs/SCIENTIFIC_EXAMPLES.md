# 공식집 레이아웃 수정과 수학·과학 예제

## 화면 수정

공식집에는 단계 번호가 없는데 단계별 사용 안내와 같은 2열 grid를 사용하면서, 본문 전체가 30px 번호 열에 배치되어 있었습니다. 공식집은 단일 본문으로 분리하고 단계별 안내에는 `minmax(0, 1fr)` 본문 열을 지정했습니다. 긴 표는 본문 너비를 유지하며 표 안에서만 가로 스크롤합니다.

상단 **사용 가이드 · 공식집**에서 **함수·문법**과 **사용 방법**을 각각 선택합니다. 본문만 세로로 스크롤하고 닫기·내용 선택·복귀 버튼은 고정합니다. 휴대전화에서는 헤더를 줄여 본문 공간을 확보했습니다. 두 화면 모두 실제 브라우저의 본문 너비를 검사하여, 글자 존재 여부만 검사하던 이전 검사의 누락을 보완했습니다.

## 예제 여는 방법

**Equation Solver → 수식·파라미터 → Nonlinear → 예제 불러오기**에서 선택합니다. 기존 기초 예제 5개에 아래 8개를 추가했습니다. 메뉴는 긴 목록을 스크롤할 수 있습니다. 예제 선택 시 현재 모델을 바꾸며, 기존 프로젝트가 필요하면 먼저 저장합니다. 기존 되돌리기 동작을 유지합니다.

선택 후 **예제 관찰 안내**를 펼치면 모형의 의미, 조작 순서, 임계값과 배경 자료 링크가 나옵니다. **시뮬레이션 → 시뮬레이션 병합 세트 추가**로 여러 해를 한 그래프에서 색상별로 비교합니다. 해의 생성·병합을 보려면 처음에는 여러 해가 존재하는 기본값에서 세트를 만드세요. 다른 고정 파라미터는 유지하고 탐색 변수만 움직이면 기준 곡선이 유지됩니다.

| 예제                       | 기본값의 실근 수 | 살펴볼 기능                                              |
| -------------------------- | ---------------: | -------------------------------------------------------- |
| Landau 모형의 평형 분기    |                3 | `x³−x=h`, `h=±2/(3√3)`의 두 fold, 세 가지 병합           |
| 평균장 Ising 모형의 자기화 |                3 | `m=tanh(βm+h)`, `β=2`에서 `h≈±0.53284`의 분기 끝점       |
| Semenov 열폭주 임계점      |                2 | `exp(θ)=qθ`, `q=e, θ=1`에서 정상 열수지 해의 병합        |
| van der Waals 등온선       |                3 | 환산 상태방정식, `T=0.9`의 세 체적과 스피노달 끝점       |
| 삼각·쌍곡함수의 교점 병합  |                3 | 번호 함수의 조합, `tr≈0.8292548, 1.0648626`의 두 접점    |
| 4차 접점에서 생기는 두 해  |                2 | `(x−1)⁴=p`, 4중근과 두 실근의 생성·병합                  |
| 3차 변곡 접점을 지나는 해  |                1 | `x³=p`, 소멸 없이 0을 통과하는 유일 실근                 |
| A+B ⇌ C의 비선형 화학평형  |                2 | 세 변수, 혼합식·물질수지·질량작용 법칙, 가능한 농도 선택 |

각 모델의 배경 링크는 실행 예제의 관찰 안내에 포함되어 있습니다. 교과서에서 쓰이는 수학·물리·화학 모형에 교육용 수치를 적용했습니다. 실험 데이터의 적합 결과나 실제 물질의 운전 조건은 아닙니다. 정적 평형식이며 시간에 대한 ODE 시뮬레이션은 하지 않습니다.

Ising의 열역학적 안정성, van der Waals의 Maxwell 등면적 구성, 열폭주의 시간적 발산은 현재 계산하지 않습니다. 3차 변곡 접점은 두 파라미터의 일반 Cusp 분기 전체를 뜻하지 않습니다. 분기 끝점의 수치 한계는 [KNOWN_ISSUES.md](KNOWN_ISSUES.md)를 유지합니다.

## 검증

- 전체 단위 검사 **333개 통과**. 새 예제 8개의 초기 실근 수를 확인하고 곡선의 유효한 지점들을 소스와 독립적인 수식으로 다시 대입해 잔차를 검사했습니다. 스칼라 접점 예제 7개 모두 해당 차수의 검증된 접점 표시를 확인했습니다.
- Landau의 해석적 임계값 양쪽에서 실근 수가 3→1로 달라지는 것을 확인했습니다.
- TypeScript·프로덕션 빌드, 핵심 코드 문서 3개의 원본 일치 검사 통과.
- 브라우저에서는 데스크톱 1440px·모바일 390px 공식집/사용 방법의 너비·스크롤, Landau·Ising·Semenov·van der Waals 병합 곡선과 파라미터 변경 시 기준 곡선 보존을 검증했습니다. 대상 브라우저 시나리오 8개를 확인했습니다.
