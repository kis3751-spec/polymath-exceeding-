# 인계할 분기 추적 문제

사용자의 사용량 제한 요청에 따라 검증된 화면·파서·워커·저장 개선을 먼저 반영합니다. 아래 문제는 해결 완료로 간주하지 않습니다. 이번 기준 상태는 단위 검사 309개와 브라우저 검사 42개가 통과했지만, 배포용 추가 확인에서 다음 경로 문제가 발견되었습니다.

## 1. 격자에 없는 특이점을 지나는 현재값 추적 실패

- 모드: Nonlinear 자동 탐색.
- 수식: `x^3 = 2-a`.
- 파라미터: `a=0`, 최소 0, 최대 3, 간격 0.1.
- 시작 해: `x ≈ 1.2599210499`.
- 재현: `a`를 2로 바꾸면 현재 해 0을 표시하지만, 이어서 3으로 바꾸면 현재 선택한 해가 없다고 표시합니다. 기대값은 **-1**입니다.
- 그래프·표의 `a=3` 계산 지점은 -1일 수 있어 현재값 표시와 일치하지 않습니다.

`src/engine/simulation-panels.ts`는 불변 기준점에서 현재 설정까지 `continueRoot`를 호출합니다. `src/engine/branches.ts`의 현재값 경로는 구간을 16개로 나누는데, 0→3 경로에서 특이점 `a=2`를 정확히 밟지 않습니다. 반면 간격 0.1의 표는 2를 포함합니다. 끝점이 정확히 특이점인 검사만으로는 이 차이를 검출하지 못했습니다.

현재값 0→3 및 2.000001, 그리고 특이점을 포함하지 않는 그래프·표 격자도 별도로 검증해야 합니다. 단순히 보정 허용치를 크게 하거나 작은 값을 일괄 0으로 만들면 안 됩니다.

## 2. 직접 추적에서 파라미터 극점을 건너는 안전성 문제

엔진 직접 검사에서 `x=1/p`를 기준 `p=1, x=1`에서 `p=-0.9`까지 추적할 때, 중간의 `p=0`을 지나 다른 연속 구간의 해로 이동할 수 있는 사례가 확인되었습니다. 화면 전체 동작으로의 재현은 아직 추가 검증하지 않았습니다.

다음 두 성질을 함께 검증해야 합니다.

- `x^3=2-a`처럼 유효한 연속 분기는 특이점을 밟지 않아도 이어져야 합니다.
- `x=1/p`, `x=1/(p-0.1)^2`처럼 중간에 발산하는 분기는 연결하면 안 됩니다.

끝점에서 각각 유일한 실근이 있다는 사실이나 역방향 복귀만으로 경로 전체의 연속성이 보장되지는 않습니다. 파라미터 분모와 최고차항의 변화도 확인해야 하며, 최고차항이 0이어도 유한한 해가 남는 `p*x^3+x=1` 같은 사례를 무조건 차단해서도 안 됩니다.

## 보존한 미완성 작업

[continuation-path.patch](work-in-progress/continuation-path.patch)에 마지막 검증 이후의 미완성 엔진 변경과 추가 회귀 사례를 보존했습니다. 이 패치는 **검증을 마친 수정이 아니며 실행 소스에 적용하지 않았습니다.** 다른 개발자가 검토를 이어갈 때 참고하기 위한 자료입니다.

패치를 적용해 검토할 경우 대상은 `automatic-polynomial.ts`, `automatic.ts`, `branches.ts`, `root-isolation.ts`, 미완성 `parameter-path.ts`와 관련 테스트입니다. 단위 검사, 현재값 경로 검사, 특이점 없는 격자 검사와 실제 브라우저 동작을 모두 확인한 뒤에만 해결 완료로 표시해야 합니다.
