# 미분방정식 모듈

브라우저 Worker에서 초기값 상미분방정식과 연립식을 적분합니다. 기존 Equation Solver의 허용 수학 함수와 번호 있는 재사용 수식 문법을 사용하며, 사용자 입력을 JavaScript로 실행하지 않습니다.

## 입력

다음 세 미분 표기를 지원합니다. 모두 한 문제에서 하나의 독립변수를 사용합니다.

```text
d(A)/d(t) = -k*A
dA/dt = -k*A
A' = -k*A
```

초기값은 `A(0)=1` 또는 `A|1`로 지정합니다. 독립변수는 `t(0)=0`과 `t(f)=10`, 또는 `t|0:10`으로 지정합니다. 초기값·범위는 유한한 숫자여야 하고 끝은 시작보다 커야 합니다. 같은 변수를 중복 정의하거나 미분 변수에 최종값을 지정하면 오류로 안내합니다.

```text
d(A)/d(t) = -r
r = k*A
k = 0.3
A(0) = 10
t|0:5
```

보조식은 입력 순서와 관계없이 의존 순서로 계산합니다. 미정의 변수·순환 참조를 거부합니다. UI에서 `k`를 바꾸면 원래 숫자 상수 정의를 재사용해 다시 계산합니다. 상태변수·동적 보조식을 슬라이더 값으로 덮어쓰지는 않습니다.

`f1(A)=-k*A`를 정의한 뒤 `d(A)/d(t)=f1(A)`처럼 재사용할 수도 있습니다. 여러 상태변수를 함께 쓰는 수식은 인자 없는 `f1=...` 형태를 사용합니다.

## 해법과 오차 해석

- **RK45**: Dormand–Prince 5(4)의 두 차수 차이로 각 스텝의 오차를 추정하고 스텝 길이를 조정합니다.
- **암시적 해법**: Backward Euler를 한 번의 전체 스텝과 두 번의 절반 스텝으로 풀어 차이를 비교합니다. 단계별 연립식은 감쇠 Newton과 피벗팅 선형 풀이로 보정합니다. 1차 해법이며, SciPy Radau/BDF와 동일한 구현이 아닙니다.
- **자동**: RK45의 반복적인 거부 또는 진행량에 비해 많은 스텝을 감지하면 암시적 해법으로 전환합니다. 실제 적용 경로를 방법명에 표시하며 이 휴리스틱을 강성의 수학적 판정으로 표현하지 않습니다.

상대 허용치를 `tol`이라 할 때 각 성분의 국소 오차 척도는 `tol × (0.01 + max(|이전값|, |다음값|))`입니다. 즉 절대 오차의 바닥 척도는 `0.01×tol`입니다. 리포트의 최대 국소 오차 추정은 승인한 스텝의 해 차이입니다. 누적 전역 오차의 엄밀한 상한, 실제 입력의 측정 정확도나 확률을 뜻하지 않습니다. 암시적 1차 해법은 같은 국소 허용치에서 RK45보다 누적 오차가 클 수 있으므로 정확도가 중요하면 더 작은 허용치와 독립 해석해·보존량을 함께 확인하세요.

출력 행은 지정한 균일 격자에 **실제로 도달한 승인 스텝의 끝점**입니다. 출력 시각 사이를 화면에서 연결한 선은 보간 표시이며, 표본 사이의 모든 연속 극값·이벤트를 분리한 것은 아닙니다.

## 중단과 지원 범위

정의역 이탈·발산·Newton 실패·스텝 표현 불가·예산 초과는 성공으로 표시하지 않습니다. 중단 결과는 `status=stopped`, 마지막 완료 시각, 사유와 부분 궤적을 반환합니다. 최소 스텝이라는 이유만으로 오차 조건에 실패한 값을 승인하지 않습니다.

- 초기값 ODE만 지원합니다. 경계값 문제, PDE, 일반 DAE·대수 제약 연립식은 포함하지 않습니다.
- 미분 변수 최대 32개, 보조식 256개, 출력 2~5,000행, 적분 시도 최대 200,000회, RHS 평가 1,000,000회, 계산 시간 약 3.5초의 한도를 둡니다.
- 상대 허용치는 `1e-12~0.01`에서 선택합니다. Float64의 유한 정밀도를 넘는 정확도를 약속하지 않습니다.
- 정의역이 열린 로그·제곱근 경계나 빠른 비매끄러운 전환에서 적분이 중단될 수 있습니다. 이벤트 위치의 엄밀한 분리나 자동 positivity 제약은 구현하지 않았습니다.

대표 예제는 순차 화학 반응의 질량 보존, 감쇠 진동자, Robertson 강성 반응계입니다. 검사는 해석적 지수 감쇠·삼각함수 궤적·반응 보존량·강성 강제 응답·중단 사례로 수행합니다.
