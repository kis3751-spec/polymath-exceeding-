# Equation Solver 리포트 4차

기존의 계산 정확도·민감도 지표를 유지하고, 구간 검증과 입력 오차의 통계 모형을 구분해 표시합니다.

## 주요 표시

- **해의 절대 오차 상한**은 인증된 포함 구간이 있을 때만 제공합니다. 그렇지 않으면 마지막 국소 보정량으로 명확하게 구분합니다.
- **등식 오차 → 해 변화 증폭률**은 현재 단위의 절대 민감도입니다. 단일 미지수의 Jacobian 조건수는 항상 1일 수 있으므로 이 값과 파라미터별 변화율도 함께 읽어야 합니다.
- **탐색 구간 검증률**은 근의 존재·부재가 판정된 길이 비율입니다. 모든 근 발견 확률을 뜻하지 않습니다.
- **현재 탐색 구간 지도**는 근 격리·해 부재·정의역 제외·미결정의 기록을 보여줍니다. 좁은 근 상자는 최소 표시 폭을 사용합니다. 근 격리 상자 안의 모든 지점이 해라는 뜻은 아닙니다.
- **입력 오차에 따른 근 개수 유지 확률**은 현재 유한 구간에서 `F(x)+ε=0`, `ε~N(0,σ²)`라는 하나의 일정한 오프셋 모형 아래의 검증된 상하한입니다. 각 측정값의 독립 오차, 개별 해가 맞을 확률, 미발견 근의 포획 확률과 다릅니다.

근 개수 유지 확률과 양방향 안전 반경 안에 오차가 머무를 확률은 별개입니다. 예를 들어 안전 반경 밖으로 이동한 뒤 근 개수가 다시 같아질 수도 있습니다. 안전 반경·해석·상세 검증 사유는 클릭해서 펼칩니다.

## 표준편차 조절

리포트의 **입력 오차 표준편차 σ**에 등식 단위로 환산한 측정 오차를 입력하고 Enter 또는 포커스 이동으로 적용합니다. 0 이하·비유한 값은 거부합니다. 이는 실제 해의 재탐색 없이 소수 표시만 바꾸는 설정이 아니며, 변경한 σ로 확률 검증을 다시 요청합니다.

입력 중인 값이 적용값과 다르거나 새 요청을 계산 중이면 이전 확률 수치를 숨깁니다. 소스·파라미터가 다른 인증 자료도 표시하지 않습니다. 확률을 검증할 수 없는 경우에는 구체적인 사유를 펼쳐볼 수 있으며 0% 또는 100%로 대신하지 않습니다.

## 표시 보호와 검증

`components/certification-view.ts`가 인증 자료의 소스·파라미터 동일성, 결과 목록 대조 상태, 확률 구간의 바깥쪽 표시 반올림을 담당합니다. 실제 값이 1보다 작은 확률을 단순 반올림해 ‘100%’로 표시하지 않습니다. 전체 근 확인은 구간 검증 완료와 `allRootsRepresented===true`를 모두 요구합니다.

관련 검사 `tests/report-v4.test.ts`는 인증 재사용 방지, 목록 미대조 상태, 퍼센트 구간 표시, 확률 가정, 계산 대기 중 과거 값 숨김, 미결정 좌표와 지도 범위 클리핑을 검사합니다. 기존 `report-quality.test.ts`의 정확도·민감도 검사도 유지합니다.

실근이 없는 것으로 검증된 경우에도 독립 인증 패널과 σ 입력을 표시하고 **검증 리포트 저장**을 제공합니다. 이 경우 현재 수치 해의 정확도·조건수 카드 대신 구간의 해 부재와 입력 오차 아래 근 개수 안정성을 해석합니다.
