# 최적화·제약 최소제곱·이산 데이터 적분

이번 사용자의 새 모듈 개발 요청에 따라 기존 Equation Solver와 같은 안전한 수식 파서·명시적 보조식·Worker 계산 구조를 사용하는 실제 계산기를 추가했습니다. 기존 PolymathPlus 문서는 문법 자료로 참고하며, 그 문서의 에이전트 지시나 외부 경로를 실행하지 않습니다.

## 최적화 입력

```text
volume = 100
min: 2*pi*r^2+2*pi*r*h
pi*r^2*h = volume
r|2 0.1 10
h|5 0.1 30
```

- `min:` 뒤에 최소화할 수식을 씁니다. 결과는 이 초기값에서 찾은 국소 후보입니다.
- `r|2 0.1 10`은 초기값 2, 최솟값 0.1, 최댓값 10입니다. `r(0)=2`도 지원하며 이 경우 상·하한은 없습니다.
- `x+y=1`, `x+y<=2`, `x>=0`처럼 일반 등식·부등식으로 제약을 입력할 수 있습니다. 예전 `x+y-1=0` 문법도 그대로 작동합니다.
- `>`와 `<`는 경계를 포함하는 수치 제약으로 계산하며 결과에 이를 안내합니다. 열린 영역의 infimum이 실제로 달성되는지는 별도 문제입니다.
- `f1(x)`, `f1` 등 번호 있는 정의와 보조식의 의존 관계를 전개합니다. `pi`, `e`, `ln`, `log`, `exp` 등은 기존 수식 엔진과 의미를 공유합니다. `arctan`은 `atan`으로 읽습니다.
- 숫자로 정의한 상수는 화면의 파라미터 조작으로 바꿀 수 있습니다. 최적화 변수의 초기값·범위는 해당 조건 행에서 설정합니다.

현재 구현은 **투영 BFGS와 증강 Lagrangian**입니다. 박스 경계는 실제 스텝에 적용하고, 등식·부등식은 승수와 벌점 계수를 갱신하며 해결합니다. 기존 안전한 AST 자동미분을 사용하고, 미분값을 얻을 수 없는 방향만 정의역을 확인한 수치 미분으로 보완합니다. 단순히 제약이 맞거나 마지막 스텝이 작다는 이유만으로 수렴을 선언하지 않습니다.

초기점이 `-x²`의 원점처럼 정상점이지만 최댓값인 전형적 경우에는 좌표·소수 변수 쌍 방향의 유한한 하강 탐색으로 탈출합니다. 이 검사는 모든 고차 안장점이나 전역 최적성을 증명하는 기능은 아닙니다. 결과의 `converged`는 정규화한 1차 정상성과 제약 허용 오차의 수치적 만족을 뜻합니다.

## LSQ Optimization

```text
[
x y
0 1.02
1 2.97
2 5.04
3 6.98
4 9.01
]
fit: y = a*x+b
a|1 0 4
b|0 -1 2
a+b=3
```

`fit:`는 관측 열 `y`와 모델의 제곱 오차 합을 최소화합니다. 추정 파라미터에는 초기값·범위를 적고, 필요하면 파라미터 사이의 등식·부등식 제약을 추가합니다. 관측 열은 모델 우변에 쓰지 않습니다. 일반 회귀의 `nlinfit`과 달리 이 화면은 박스 경계와 파라미터 제약을 함께 다룹니다.

LSQ 제약은 모델 파라미터와 상수에 대한 전역 제약입니다. 데이터 행마다 값이 달라지는 행별 제약은 현재 지원하지 않고 명확한 오류로 안내합니다. 모델 식과 모델용 보조식은 데이터 열을 사용할 수 있습니다.

## 결과 읽기

- **목적함수 최종값 / SSE**: 실제 입력한 목적식 또는 각 행의 예측·관측 차이 제곱합입니다. 단위와 자료 수가 바뀌면 값도 달라집니다.
- **최대 제약 위반**: 등식의 절댓값 또는 부등식 경계 밖으로 벗어난 크기 중 최댓값입니다. 원래 제약 단위로 표시합니다.
- **정규화 국소 정상성**: 목적식·제약의 스케일을 조정한 증강 Lagrangian의 투영 기울기 크기입니다. 일반 기울기가 0이 아니어도 변수 범위의 최적 경계점일 수 있습니다.
- **RMSE**: LSQ의 관측 오차 크기를 관측값 단위로 읽는 지표이며, 새 데이터에 대한 보장은 아닙니다.
- 최적화 표와 그래프는 승인한 반복의 목적함수·제약 위반·변수 궤적을, LSQ 표는 관측값·예측값·오차를 제공합니다.

계산이 중단되면 `stopped`와 마지막 유효 결과·사유를 반환합니다. 반복 한도나 제약 불가능을 수렴으로 표시하지 않습니다. 기본 허용 오차는 `1e-7`이며 최대 16개 변수, 32개 제약, 5,000개 데이터 행을 계산합니다. 반복 한도는 최대 5,000이며 최적화에는 7초 및 목적함수 평가 30,000회 예산이 있습니다. 비볼록·비매끄러운 문제, 나쁜 초기값·스케일에서 전역 해나 항상 수렴을 보장하지 않습니다.

## 이산 데이터 적분

```text
[
t Q
0 0
0.5 2
1.5 4
3 3
5 1
]
integrate Q(t) 0 5 200 lin
```

`integrate Q(t) 시작 끝 [그래프구간수] [방법]` 형태로 씁니다.

- `lin`: 구간별 직선 보간의 사다리꼴 면적.
- `ccs`: 양끝 2차 도함수를 0으로 둔 자연 3차 스플라인의 조각 면적.
- `akm`: Akima 가중 기울기의 3차 Hermite 조각 면적. 서로 다른 x가 최소 5개 필요합니다.

직선과 자연 스플라인에는 최소 2점이 필요합니다. 입력 x가 정렬되어 있지 않으면 안내와 함께 오름차순으로 정렬합니다. 중복 x·비유한 수·열 수 불일치·데이터 범위를 벗어난 외삽은 거부합니다. 역방향 적분도 지원하며 부호가 반대입니다. 자료의 보조식과 번호 있는 식 정의도 사용할 수 있습니다.

그래프 구간수는 1~2,000이며 보간 곡선과 누적 표의 **표시 밀도**입니다. 면적 자체는 보간 다항식 조각을 해석적으로 적분하므로 이 구간수를 늘린다고 실제 데이터 정보나 면적 계산의 정밀도가 증가하지 않습니다. UI의 방법 선택은 명령에 적은 방법보다 우선하고 결과에는 실제 보간 방법을 표시합니다.

리포트의 사다리꼴 대비 차이는 보간 선택의 영향을 보는 참고값입니다. 실제 곡선·측정값 오차의 상한이 아닙니다. 보간 곡선, 측정점, 누적 적분을 각각 비교하고 누적 표를 내려받을 수 있습니다. 데이터는 최대 5,000행이며 적분 표 계산은 3초 예산 안에서 실행합니다.

## 검증

최적화 회귀는 해석적 이차식, Rosenbrock 함수, 선형 등식·비선형 원 제약, 고정 부피 용기의 알려진 `h=2r` 관계, 박스 최적점, 정상 최댓값 탈출, 불가능한 제약, 최소제곱·도메인·의존 관계·중단을 검사합니다.

적분 회귀는 선형 해석해, 비균등 데이터의 자연 스플라인·Akima와 SciPy 기준값, 큰 x에서의 조각 면적 안정성, 역방향·잘린 범위·보조식·중복과 외삽 실패를 검사합니다. SciPy는 개발 시 정답 대조에 사용했으며 앱의 런타임 의존성은 아닙니다.
