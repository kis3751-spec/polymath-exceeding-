# 대표 예제와 재현 오류 정리

2026-11-09. Equation Solver의 현재 기능에 적용했습니다.

## 예제 메뉴: 대표 6개

- 제곱식의 두 실근: 등식 입력과 기본 해 탐색.
- 원과 직선의 교점: 다변수 연립식.
- Landau 평형 분기: 세 해, 근 병합과 병합 세트.
- 몰체적 van der Waals: 단위가 있는 공학 파라미터와 유리식의 작은 세 근.
- cos·sinh 교점: 번호 있는 함수 정의, 함수 조합, 초월함수 접점.
- 세제곱근 관통: 홀수 중근이 병합과 다르다는 점.

이전 모델은 메뉴에서 제거했습니다. 엔진 회귀 검사용 전체 카탈로그는 내부에 보존하여 예제를 줄인 뒤에도 기존 계산을 검증합니다. 준비 중인 다른 계산 모듈은 추가하지 않았습니다.

## 해결한 문제

1. **숨은 파라미터 극점(K01)**: 파라미터 분모를 경로 전체의 구간으로 평가합니다. `1/sin(100*p)`처럼 시작·끝의 값이 같아도 중간에 극점이 있으면 연속 추적을 거부합니다. 안전한 작은 이동은 허용합니다. 여러 파라미터가 바뀌는 경우에는 경로를 포함하는 상자로 보수적으로 검사합니다. 미지원 구간 함수의 분모는 안전하다고 가정하지 않습니다.
2. **큰 공통항 상쇄(K03)**: 원래 식의 덧셈·뺄셈 트리 전체를 Neumaier 보상 합산합니다. `(1e16+x)-1e16=1`과 부호가 반대인 대응식의 `x=1`을 반환합니다. 0으로 나누는 항을 상쇄하여 정의역을 넓히지 않습니다. 함수·곱셈 등 모든 중간 연산을 임의정밀도로 바꾼 것은 아닙니다.
3. **접점과 곡선의 간극(K04)**: 기준 곡선을 생성할 때만 검증된 종료점의 해를 원래 모델에서 다시 확인하여 곡선에 추가합니다. 연결 사이의 잘못된 빈 표본을 제거하며 현재값 이동으로 기준 곡선을 다시 쓰지 않습니다. 데이터셋은 지정한 샘플 간격을 그대로 사용합니다. 원래 모델에서 끝점을 재확인하지 못하면 억지로 연결하지 않습니다.
4. **양의 정수 거듭제곱 중근의 검증 보류 일부(L01)**: `G(x)^n=0`에서 양의 정수 n은 영점 집합을 바꾸지 않으므로 G의 근 구간을 검증합니다. 리포트에 이 동치 변환을 명시하며 원래 식·파라미터를 보존합니다. 인증된 서로 다른 근의 개수와 수치적 중복도 판정을 구분합니다. 일반적인 중근 인증·로그 경계 증명 전체의 해결은 아닙니다.
5. **제곱근 지수 구간 검증(L02 일부)**: `x^0.5`와 `pow(x,0.5)`를 `sqrt(x)`와 동일한 구간 연산·정의역으로 처리합니다. 일반 비정수 지수를 무조건 지원한다고 바꾸지 않습니다.
