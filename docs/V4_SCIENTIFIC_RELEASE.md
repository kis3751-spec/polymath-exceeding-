## 첨부 문서의 적용 방식

- `확률검증4차.md` (SHA-256 `20440b44c08229a38537fcc14de395607e0f174672eb6eeef102257f686fd444`): 현재 엔진의 입력·분기·중근 API를 유지하면서 구간 산술·인증 모듈을 보완해 통합했습니다. 과거 parser/solver 10개 파일을 통째로 덮지 않았습니다.
- `Pasted text.txt` (SHA-256 `bfe939ab7172e50f9f3a5dfa5a678a7be07e2b4121ae1fbc790f32f5e3834614`): DEQ·REG·NLP의 문법과 모델 예제를 참고했습니다. 파일 안의 에이전트 운영 지시를 사용자 요청으로 취급하지 않았고, 기존 Equation Solver의 일반 등식·번호 함수 문법을 보존했습니다.

## 시작 화면에서 사용하는 방법

| 홈 카드                | 제공 기능                                           | 첫 사용                                                                       |
| ---------------------- | --------------------------------------------------- | ----------------------------------------------------------------------------- |
| Equation Solver        | 선형·비선형 실근과 분기 추적, 구간 인증·확률 리포트 | 기존 모델을 그대로 사용합니다. 리포트의 σ를 바꾸면 실제 재인증합니다.         |
| Differential Equations | ODE·연립 ODE, 자동 RK45/강성 대응 음해법            | 초기값과 시간 범위를 입력하고 시간 재생·위상 그래프를 확인합니다.             |
| Curve Fitting          | 선형·다항식·다중선형 회귀                           | `polyfit x y 1`의 차수를 바꾸거나 상단 ‘회귀 모델’에서 다중선형을 선택합니다. |
| Nonlinear Fitting      | 비선형 데이터 회귀                                  | `nlinfit` 모델과 `m(계수)=초기값`을 입력합니다.                               |
| Optimum Finder         | 제약 목적함수·LSQ 최적화                            | 상단 ‘최적화 방식’에서 목적함수 또는 LSQ를 선택합니다.                        |
| Discrete Integration   | 구간별 선형·자연 3차 스플라인·Akima 적분            | 측정 표와 `integrate` 명령을 입력합니다. 측정·보간과 누적 적분을 나눠 봅니다. |

각 모듈은 **모델·데이터 / 시뮬레이션 / 해석 리포트** 화면을 분리합니다. 초기 예제·사용법, 모듈별 자동 저장, 프로젝트 JSON 저장/불러오기, 전체 데이터 CSV, Markdown 리포트를 제공합니다. ODE는 시간 선택·재생·위상 변수 선택과 상수 조절을 지원합니다. 회귀는 데이터 오차를, LSQ는 수렴 이력을 별도 축으로 표시합니다.

새 과학 계산은 ES 모듈 Worker에서 실행하며, 새 요청이 들어오면 이전 Worker를 종료합니다. 기존 WebAssembly 선형 커널은 그대로 사용합니다. Python·서버·외부 API는 앱 실행에 필요하지 않습니다. 검증에 사용한 SciPy·고정밀 기준은 앱의 실행 의존성이 아닙니다.

## 확률과 리포트의 변경

원래 수식의 작은 항을 보존하는 exact AST 계수, 검증된 `erf`/Gaussian CDF, 원래 함수의 임계점과 열린 끝점 처리를 통합했습니다. 목록 대조 전 완료 판정, 서로 닿는 근 구간의 잘못된 병합, 큰 오프셋에서 근 개수가 회복되는 경우와 큰 수 슬랩의 오버플로도 보완했습니다.

리포트는 근 격리·해 부재·정의역 제외·미결정 영역을 보여 줍니다. Gaussian 값은 **명시한 단일 상수 오프셋에서 현재 유한 범위의 근 개수 유지 확률**이며 모든 근 포획 확률과 구분합니다. 현재 식에 실근이 없다고 검증된 경우에도 확률과 검증 리포트를 열고 저장할 수 있습니다. 수치가 없는 경우를 0%로 바꾸지 않으며, 화면과 Markdown 모두 검증된 상하한을 사용합니다.

## 검증

- 전체 단위 검사: **33개 파일, 727개 통과**.
- 확률 회귀: 기존 확장 반례 127개 + 추가 수학 반례 6개 + Markdown 확률 출력 3개 = **136개 통과**.
- 과학 계산: 해석적 감쇠·진동·질량보존, 독립 SciPy Radau의 Robertson 기준값, SVD 회귀·Michaelis–Menten, 비균등 데이터의 SciPy 스플라인/Akima 비교, Rosenbrock·제약 설계·LSQ 및 실패 입력을 검사했습니다.
- 배포 빌드: `npm run build` 통과. 동적 계산 엔진 로딩을 위해 `worker.format='es'`를 사용합니다. 기존 500 kB 초과 초기 JS 청크 안내는 남아 있으며 빌드 오류는 아닙니다.
- 배포 빌드 브라우저: **관련 17개 시나리오 통과**. 새 도구 전부, 선형·다항·다중·비선형 모델, 시간 재생·위상 전환·파라미터 재계산, CSV/Markdown, 모바일·가이드·프로젝트 검증, σ 재계산·무근 리포트와 기존 병합/스크롤 회귀를 포함합니다. 기존의 모든 Playwright 시나리오를 이번에 전부 재실행한 것은 아닙니다.
- 핵심 코드 Markdown 4개 재생성 및 `docs:core -- --check`, `git diff --check` 통과.
