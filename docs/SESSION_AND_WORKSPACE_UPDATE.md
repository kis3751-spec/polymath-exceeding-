# Session and Workspace Update · 2026-11-11

이번 요청의 범위는 유효한 로그인이 홈으로 밀려나는 문제, 초대 입력 혼동, 계산기 상단 UI·설정 설명, 지정 상수 조절 및 수식 축 표현입니다.

## Login and invitations

- 클라이언트가 한 번의 `SESSION_REQUIRED` 응답이나 다른 탭의 logout 알림만으로 세션을 지우지 않습니다. 현재 쿠키로 새 요청을 보내 다시 확인합니다. 확인에 실패하면 작업 화면을 가리고 연결을 재시도하며, 실제 만료·회수가 확인된 경우 로그인 화면으로 이동합니다.
- 관리자 조회도 세션을 재확인합니다. 쓰기는 서버가 처리 전 거부를 명시한 경우에만 현재 계정 ID와 최신 CSRF를 확인한 뒤 한 번 복구합니다. 비밀번호 오류·알 수 없는 네트워크 결과는 반복하지 않습니다.
- 최대 30일·7일 미사용 종료, HttpOnly/Secure 쿠키, Origin/CSRF 검사 및 즉시 권한 회수를 유지합니다. 실제 사용자 DB와 비밀번호는 변경하지 않았습니다.
- Invitation link or code는 링크 전체 또는 43자리 일회용 코드를 받습니다. 이메일을 넣으면 명확한 안내를 표시합니다. 붙여넣은 URL로 이동하거나 그 외부 서버에 요청하지 않고 fragment의 토큰만 현재 IVC 서버에서 검증합니다.

## Common workspace controls

모든 과학 도구의 상단을 Equation Solver와 같은 New / Import / Save Project / Autosaved / User Guide 구성으로 맞췄습니다. New는 빈 모델을 만들며 Undo New로 복원할 수 있습니다. Linear/Polynomial, Multilinear, Nonlinear Regression, Integration, Constrained/LSQ Optimization의 Settings 설명은 각각의 실제 옵션과 해석을 설명합니다.

ODE 등 과학 모듈은 숫자 리터럴로 지정한 상수를 자동 표시합니다. Equation Solver는 다른 식에 사용되는 유일한 숫자 정의를 Parameter로 등록합니다. `k=4; x^2=k`에서는 k가 조절값이고 x를 풉니다. 단독 `x=2` 및 기존 e/pi 미지수는 보존합니다. 엔진의 일반 등식 문법을 일괄 교체하지 않습니다.

Remove Parameter는 마지막 현재값을 고정하고 슬라이더만 숨깁니다. Restore로 다시 표시합니다. 값·범위·간격·숨김 상태는 저장되며, 과학 모듈의 관련 없는 소스 수정은 고정 값을 버리지 않습니다. 정의 자체를 바꾸면 새 정의 값을 사용합니다. Equation Solver의 Sample Spacing은 샘플 격자 간격이고 과학 모듈에서는 ± Step 이동 간격입니다. 슬라이더 현재값은 연속입니다.

## Axis Expressions

모든 그래프는 기본 축을 유지하며 선택적으로 X/Y 수식을 적용합니다. 예: X=`log(x)`, Y=`2*y+1`. x/y는 해당 그래프의 원래 좌표를 뜻합니다. 제한된 기존 AST 파서로 최대 512자의 식을 검증하며 JavaScript 실행 기능을 사용하지 않습니다.

- 계산 결과·표·CSV·수치 리포트는 원본을 유지합니다. 축 설정은 프로젝트 JSON과 계정별 자동 저장에 포함됩니다.
- 유한하지 않은 변환 지점은 인덱스를 유지한 빈 구간으로 표시합니다. 로그 정의역 등으로 생긴 누락 지점 수를 표시합니다.
- 클릭은 변환된 화면에서 가장 가까운 원본 샘플 인덱스로 연결합니다. 비단조·비가역 변환을 임의로 역산하여 파라미터를 바꾸지 않습니다.
- 원래 y=x 비교선은 같은 식으로 변환합니다. 적분의 변환 화면에서는 원래 적분으로 오해할 수 있는 음영을 생략합니다.
- Equation Solver의 변환 화면은 샘플 선택을 지원합니다. 원래 연속 보간·접점·현재 위치 도구는 Original Axes로 돌아가 사용합니다. 유효한 표본 사이를 연결하는 표시이며 임의 변환의 모든 특이점 검출을 증명하는 기능은 아닙니다.
- 기본 병합 그래프가 아래로 밀리는 문제는 축·범위 설정을 기존 조작 행에 접어 넣어 해결했습니다. 모바일에서도 가로 넘침이 없는지 확인했습니다.

## 추가 접속 복구 · 2026-11-11

Public 적용 후 외부 API/JS/CSS는 정상인데 기본 소개 주소만 다른 HTML을 반환하는 응답을 확인했습니다. 사용자가 새 쿼리 주소에서 소개 화면과 계산기 로그인까지 정상 접속했다고 확인했습니다. 이후 생성하는 소개·관리·로그아웃·초대 링크와 공개 검사에 `_ivc_page` 요청 식별자를 적용합니다. Site 주소 전체를 공유하며 Origin 설정에는 쿼리를 넣지 않습니다. 이는 캐시·전달 경로의 재사용을 피하는 탐색 변경이며 로그인 유효 기간이나 인증 권한을 변경하지 않습니다.
