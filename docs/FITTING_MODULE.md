# 회귀 모듈

사용자가 2026-11-09 승인한 신규 범위입니다. 기존 Equation Solver의 수식 파서와 제한된 AST 평가를 사용하며 수식을 JavaScript로 실행하지 않습니다. 데이터 표·명령 문법은 첨부 PolymathPlus REG를 바탕으로 하고, 기존 프로젝트의 번호 함수와 외부 파라미터 조절을 연결했습니다.

## 입력과 결과

한 개의 `[ ... ]` 표에 열 이름과 숫자 데이터를 적고, 다음 명령 중 하나를 사용합니다.

```text
[
x y
0 2
1 5
2 8
3 11
]
polyfit x y 1
```

- **Linear / Polynomial:** `polyfit x y 차수 [origin]`. 차수는 1~12의 정수입니다. `origin`은 상수항 0을 강제합니다.
- **Multilinear:** `mlinfit x1 x2 ... y [origin]`. 마지막 변수가 종속변수이고 최대 24개 설명변수를 지원합니다.
- **Nonlinear:** `nlinfit y = 수식`, 각 추정 계수는 `m(a)=초기값` 또는 `a(0)=초기값`으로 입력합니다. 선택적으로 `a(min)=값`, `a(max)=값`을 둘 수 있습니다. 한쪽 경계만 있어도 됩니다. 초기값을 경계 밖에서 조용히 이동시키지 않습니다.

일반 `이름=수식` 보조식은 의존 관계로 정렬하며 순환·중복 이름을 거부합니다. `f1(x)=...` 같은 번호 함수도 기존 전처리기를 사용해 펼칩니다. 숫자 상수 보조식의 외부 파라미터 조절은 모델을 다시 계산하고, 추정 계수 `m(a)`와 혼동하지 않습니다.

결과 표에는 측정 열, `prediction`, `data_error`(측정−예측)가 포함됩니다. 단일 설명변수에는 정규화한 모델에서 직접 계산한 적합 곡선과 측정점을 표시합니다. 다변수 모델은 다른 설명변수를 고정한 임의 곡선을 만들지 않고 **각 측정 행의 예측값**을 표시합니다. 데이터 오차 계열을 별도로 확인할 수 있습니다.

## 수치 계산과 수렴

선형·다항식·다중선형 회귀는 설명변수를 정규화한 **직접 SVD 최소제곱**을 사용합니다. 정규방정식 `XᵀX`를 만들지 않습니다. 랭크가 부족해 계수를 구분할 수 없으면 임의의 유일 계수를 반환하지 않고 모델 오류를 표시합니다.

다항식 결과의 `a0, a1, ...`는 원래 변수의 거듭제곱 계수입니다. 예측·그래프·데이터 오차는 정규화한 표현으로 계산해 큰 좌표 오프셋에서 상쇄를 줄입니다. 원점에서 매우 먼 고차 모델의 전개 계수는 별도로 민감할 수 있으므로 안정적인 정규화 표시식과 예측값을 함께 제공합니다.

비선형 회귀는 감쇠 Levenberg–Marquardt를 사용합니다. Jacobian은 기본적으로 기존 AST의 전방 자동미분으로 계산합니다. 일부 경계·비매끄러운 식에서만 정의역 안 유한차분으로 전환하고 이를 표시합니다. 선형 스텝은 감쇠 행을 추가한 행렬을 SVD로 풀며, 목적함수 감소·국소 기울기·계수 랭크를 확인합니다. 반복·시간 상한 또는 스텝 실패를 수렴이라고 표시하지 않습니다. 계수 경계가 있으면 스텝을 경계 안으로 투영하고, 경계를 벗어나야만 오차를 줄일 수 있는 방향은 투영 기울기에서 제외합니다. 활성 경계에 닿은 계수에는 대칭적인 표준오차를 제공하지 않고 그 이유를 표시합니다.

기본 반복 상한은 250회, 최대 2,000회입니다. 비선형 계산은 약 4초의 시간 예산으로 중단될 수 있으며 중단 시 마지막 유효 결과와 이유를 반환합니다. 최대 24개의 추정 계수를 지원합니다. 비선형 수렴은 초기값 주변의 국소 최소제곱 결과이며 전역 최적성을 증명하지 않습니다.

## 리포트 읽기

기본 화면은 모델식, Coefficients 표, RMSE, R², Observed vs Predicted 그래프를 먼저 표시합니다. Standard Error와 추가 진단·정규화 계산식·가정은 Diagnostics에 접습니다. Observed vs Predicted의 대각선은 관측값=예측값이며, 이 그래프는 신뢰 구간이나 예측 구간을 나타내지 않습니다.

- **RMSE:** 입력 측정점의 평균적인 오차 크기입니다. 종속변수와 같은 단위입니다.
- **R²:** 데이터 평균만 쓰는 기준 대비 오차 감소율입니다. 음수도 가능하며, 물리적 타당성이나 외삽 정확도를 뜻하지 않습니다. 종속변수 값이 모두 같으면 정의하지 않습니다.
- **조정 R² / AIC:** 계수 수를 고려한 상대 모델 비교 지표입니다. 같은 측정 데이터·종속변수에서 비교해야 합니다. AIC는 동일분산 Gaussian 오차 가정하에 공통 상수항을 생략했습니다.
- **자유도:** 데이터 행 수−추정 계수 수입니다. 0 이하이면 분산·표준오차를 제공하지 않습니다.
- **`SE_계수명`:** 독립·동일분산 오차와 국소 선형화 가정 아래 추정한 계수 표준오차입니다. 엄밀한 확률 보장이나 측정 신뢰도 인증이 아닙니다.
- **95% CI:** 각 계수의 Estimate ± Student-t(`df=n-p`) 임계값 × Standard Error입니다. 표에는 양끝과 반폭을 함께 표시합니다. 같은 측정·회귀 절차로 표본과 구간을 반복 생성하면, 그 구간의 약 95%가 고정된 실제 계수를 포함한다는 해석입니다. 한 번 계산한 실제 계수의 포함 확률, 예측의 정답률, 모든 계수의 동시 포함 확률을 95%라고 말하지 않습니다.
- **랭크 / 조건수:** 데이터가 각 계수의 영향을 독립적으로 구분하는지, 수치적으로 얼마나 민감한지를 보여줍니다.

여기서 사용하는 데이터 오차와 SVD는 Equation Solver의 구간 인증이나 모든 실근 발견 확률과 별개입니다. 완벽한 데이터 적합도만으로 모델이 실제 현상을 정확하게 설명한다고 결론 내리지 않습니다.

## Coefficient confidence interval의 조건과 계산

선형·다항식·다중선형 모델은 설명변수를 오차 없는 고정값으로 보고, 선택한 모델이 맞으며 관측 오차가 독립·동일분산 정규분포라는 통계 모델을 가정합니다. 정규화한 설계행렬의 SVD에서 공분산을 구합니다. 원래 변수 거듭제곱으로 전개한 다항식 계수의 SE는 변환행렬 `T`에 대해 `T Cov Tᵀ`의 대각선으로 구하며, 계수 사이의 공분산을 생략하지 않습니다. Student-t의 상측 2.5% 임계값은 불완전 beta의 연분수 평가와 이분법으로 구합니다. 이 수치는 통상적인 Float64 통계 근사이며 구간 인증 수치는 아닙니다.

비선형 회귀의 CI는 수렴한 위치에서 Jacobian으로 국소 선형화한 근사입니다. 모델의 곡률, 적은 표본, 다른 국소 최적점은 반영하지 못할 수 있습니다. 자유도 부족, 계수 랭크 부족, 활성 계수 경계 또는 수렴하지 않은 결과에는 일반적인 대칭 CI를 제공하지 않습니다. 최종 적합점에서 자동미분이 실패해 유한차분을 사용하면 정칙 미분을 확인하지 못한 것으로 보고 SE·CI·식별 랭크를 표시하지 않습니다. 예를 들어 `a+abs(a)` 또는 `max(a,0)`의 `a=0`에서 중앙차분의 기울기는 0이 아니지만, 모든 `a≤0`이 같은 예측을 만들어 계수를 식별할 수 없습니다. 차분 행렬의 수치 랭크나 작은 오차로 이를 정칙 모델로 승격하지 않습니다. 이전 반복에서만 유한차분을 사용하고 최종점은 자동미분이 가능하면 최종점의 CI를 유지합니다. 이 보수적 억제로 일부 매끄러운 모델도 AD 미지원 때문에 CI가 생략될 수 있으며, 이유를 보고서에 남깁니다. `origin`으로 고정한 상수항은 추정 계수가 아니므로 CI와 SE를 붙이지 않으며, 자유도 계산에서도 추정 계수로 세지 않습니다.

0을 포함하는 CI는 다른 계수와 함께 적합한 해당 모델의 양측 5% 검정에서 계수가 0인 경우를 배제하지 못한다는 뜻입니다. 변수가 무의미하다고 자동 판정하지 않습니다. 종속변수를 `log` 등으로 변환했다면 오차 분산과 CI의 가정도 변환된 값에 적용됩니다. 완전 적합의 0 또는 매우 작은 SE가 현실 측정의 오차까지 0이라는 증거는 아닙니다. 미래 관측값의 Prediction Interval과 가중·상관·이분산 오차 모델, 동시 신뢰 구간, nonlinear profile likelihood/Bootstrap CI는 구현하지 않았습니다.

검증: 회귀 관련 단위 검사 38개 통과. 기존 19개 외에 SciPy Student-t 임계값(df=1, 2, 5, 10, 30, 100000), df=1 Cauchy 해석식, 닫힌 형태 선형 공분산, NumPy 독립 계산의 큰 오프셋 다항식 공분산 변환, 자유도 0, 원점 고정, 거의 공선인 데이터의 큰 SE, 랭크 부족, 활성 경계·중단된 비선형 CI 억제, 비매끄러운 최종점 2개와 최종 매끄러운 점에서의 CI 유지를 포함합니다. 전체 앱 통합 검증은 상위 작업에서 별도로 수행합니다.
