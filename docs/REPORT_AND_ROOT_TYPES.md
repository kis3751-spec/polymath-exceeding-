## 일반적인 근·접점 분류

수식의 이름이나 예제 ID를 분기 조건으로 사용하지 않습니다. 원래 등식에 값을 넣고 도함수를 서로 다른 간격으로 비교합니다. 정의역을 벗어나면 한쪽 차분을 사용하며, 한쪽 차분을 썼다는 이유만으로 내부 지점을 경계로 부르지 않습니다.

| 표시                      | 의미                                                                                                   |
| ------------------------- | ------------------------------------------------------------------------------------------------------ |
| ○ 단순근                  | 1차 도함수가 수치 오차와 분리됨                                                                        |
| ◆ 근 병합 · 2/4/6/8중근   | 파라미터 방향 도함수가 0과 분리되고, 해당 차수 이전의 x 도함수가 수치 오차 범위 안에서 0인 짝수차 접점 |
| ⬡ 변곡점 통과 · 3/5/7중근 | 같은 정칙 조건의 홀수차 관통점                                                                         |
| ■ 정의역 경계             | 유효한 유한 함수값이 있고, 인접한 표현 가능한 x 값에서 실제 정의역 이탈 확인                           |
| 분기 다중근               | 중복도는 판정했지만 Fp도 0인 퇴화점. 교차·피치포크·병합을 임의 지정하지 않음                           |
| △ 추적 종료/근 병합 추정  | 수치 추적의 경계 또는 아직 국소 검증하지 못한 후보                                                     |

곡선의 종료점과 기울기 작은 표본을 후보로 삼고, 결과를 기준 곡선과 함께 캐시합니다. 현재 파라미터만 움직일 때 `panel.sweep` 배열을 바꾸지 않습니다. 보정이 충분히 수렴하지 않은 점은 작은 기울기만으로 낮은 차수의 접점으로 승인하지 않습니다. 5차가 2차로 잘못 판정되던 재현은 5차로 분류하며, 9차 식을 낮은 차수로 승인하는 인접 회귀도 검사합니다.

이는 **국소 수치 판정**입니다. 무한 차수, 모든 함수·모든 파라미터의 특이점 또는 다변수 분기 위상에 대한 증명이 아닙니다. 매끄럽지 않은 식은 미분 기반 차수를 붙이지 않습니다. 선형은 접점 분류를 호출하지 않습니다. 다변수는 랭크 진단을 제공하며 스칼라 중복도를 부여하지 않습니다.

## 리포트의 주요 지표

단일 변수 자동 탐색의 리포트에 들어가면 기존 구간 검증 옵션을 켜고 현재 모델을 검증합니다. 실제 검증 범위와 현재 파라미터를 함께 표시합니다.

1. **해의 절대 오차 상한**: 선택된 값이 유일근 인증 구간 안에 있을 때 구간 Newton 교집합으로 범위를 줄입니다. 그 범위와 계산값 사이의 최대 거리에서 바깥쪽 반올림한 상한을 표시합니다. 표시 숫자도 아래로 반올림하지 않습니다. 입력값의 측정 오차까지 포함한 상한은 아닙니다.
2. **국소 보정량**: 인증 구간이 없으면 `|J⁻¹F|`를 표시합니다. 선형계에서는 `A`를 사용합니다. 이것은 실제 오차 상한과 명확히 구분합니다.
3. **등식 오차 증폭률**: `||J⁻¹||∞`. 단일 변수는 `1/|F′|`이므로 행렬 조건수가 1이어도 큰 절대 민감도를 드러냅니다. 각 등식의 우변에 같은 절대 오차가 들어간다고 가정하며 현재 단위에 의존합니다.
4. **중근의 비선형 반응**: `m`중근에서는 `|Δx| ≈ (m!·δ/|F⁽ᵐ⁾|)^(1/m)`를 표시합니다. 작은 오차의 국소 규모 추정입니다. 오차 방향에 따라 실근이 없어질 수 있으므로 유한한 선형 증폭률로 바꾸지 않습니다.
5. **탐색 구간 검증률**: 판정한 구간 길이의 하한 비율입니다. 미결정 구간이 남으면 표시를 100%로 반올림하지 않습니다. ‘전체 n개 근 확인’은 검증 완료와 결과 목록의 일대일 대응이 모두 성립할 때만 표시합니다.
6. **파라미터별 변화율**: `dx/dp = -J⁻¹∂F/∂p`. 현재 해 주변의 국소 변화율을 펼쳐서 확인할 수 있습니다.

사용자가 ‘가정한 등식 오차 δ’를 바꾸면 예상 해 변화 크기를 즉시 확인할 수 있습니다. 조건수 norm 선택은 유지하며, Jacobian·개별 등식 오차·계산 시간·검증 근거는 작은 글씨와 접힌 상세 영역에 배치합니다. 화면 리포트와 Markdown 저장은 같은 지표 계산 함수를 사용하며, 저장에는 임의의 δ에도 사용할 수 있는 증폭률·중근 반응식을 포함합니다.

**모든 해를 발견했을 확률**을 계산하려면 미발견 근에 대한 정당화된 확률 모형이 필요합니다. 현재의 결정론적 구간 분할은 그 확률 모형을 제공하지 않습니다. 대신 증명한 근 구간 개수, 검증한 길이 비율, 미결정 구간의 위치와 사유를 직접 보고합니다. 작은 미결정 구간에도 근이 있을 수 있습니다.

## 확인한 검사와 남은 범위

- 서로 다른 계수 스케일의 2~8차 접점, 로그 정의역, 5차 오분류 재현, 9차의 잘못된 하위 차수 승인 방지.
- 초월함수 접점, 두 van der Waals 예제, Landau 모델, 기준 곡선 불변성 회귀.
- 해석적 제곱근이 포함 구간에 실제 포함되는지, 역도함수 민감도와 `dx/dp`, 6중근의 비선형 반응, 선형 후방오차.
- 일반·전체화면에서 그래프 클릭과 시뮬레이션 추가의 실제 브라우저 스크롤, 새 리포트의 반응형 표시와 내보내기.

현재 남은 수치·검증 한계는 [KNOWN_ISSUES.md](KNOWN_ISSUES.md)에 유지합니다. 해결한 5차 오분류 항목은 제거했습니다. 초월함수 파라미터 경로의 숨은 극점, 큰 수 상쇄, 접점 마커까지의 곡선 간극은 이번 수정으로 해결했다고 주장하지 않습니다.

작은 두 근의 비영 자동미분 기울기를 넓은 차분 간격이 구분하지 못할 때는 중근으로 승격하지 않습니다. 해 목록을 유지하고 차수 미분리로 안내하며 원래 기울기로 민감도를 계산합니다. 클릭 직후 휠 입력은 지연된 React 표시 상태 대신 실제 DOM 포커스를 기준으로 적용합니다.

최종 검증: `npm test` 479개 통과, `npm run build` 통과, `docs:core -- --check` 통과. 배포 빌드로 전체 Playwright 71개를 통과했고, 마지막 퇴화점 보호 조건 반영 후 영향을 받는 접점·과학 예제·휠·스크롤·리포트 15개 시나리오를 다시 통과했습니다. Vite의 JS 청크 크기 안내는 남아 있으며 빌드 오류는 없습니다.
