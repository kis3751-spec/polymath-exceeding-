# 곡선·샘플·초기값 추적 수정

검토일: 2026-11-09. 이번 범위는 Equation Solver의 기존 기능 수정이며 새 계산 모듈은 추가하지 않았습니다.

## 그래프와 빈 원이 어긋났던 이유

기존 그래프는 기본 81개 계산점을 직선으로 연결했고, 빈 원은 사용자가 정한 간격으로 따로 계산한 실제 해였습니다. 접점 근처처럼 곡률이 큰 곳에서는 두 그래프 점 사이의 직선이 실제 해를 지나지 않아 빈 원이 선에서 벗어났습니다. 마커를 선 위로 투영하면 실제 계산값을 왜곡하므로 그렇게 처리하지 않았습니다.

이제 `branches.ts`, `sweep.ts`는 표·CSV에 쓰는 모든 샘플을 그래프의 꼭짓점에도 포함합니다. 기본 렌더링 점과 추적 경계도 유지합니다. 같은 기준 해에서 탐색 파라미터의 현재값만 바꾸면 기준 배열을 재사용합니다. 샘플 사이의 선과 마우스 미리보기는 여전히 보간이며, 클릭한 현재점은 솔버로 다시 계산합니다.

## 초기값 모드의 끊김·다른 해로의 이동

예제:

```text
(x-1)(x+1)(x)=(-1/q)x+p
x(0)=10
```

`q=-2.79757392`에서 식은 `x³−a·x−p=0`, `a=1−1/q`입니다. 접점은 `x=±sqrt(a/3)`, `p=∓(2a/3)sqrt(a/3)`입니다. 양의 해에서 출발한 곡선은 음의 p 쪽 접점에서 끝나며, 그보다 작은 p에 남아 있는 음의 해는 다른 가지입니다.

기존 수동 모드는 각 샘플에서 `x(0)=10`으로 Newton을 새로 시작했습니다. 그 결과 같은 곡선 추적이 아니라 샘플별로 다른 해를 선택하거나 수렴에 실패할 수 있었습니다. 이제 `manual-simulation.ts`가 처음 선택한 실제 해를 저장하고 자동 모드와 같은 연속 추적·역방향 확인을 사용합니다. 현재 파라미터에서 추적에 실패해도 이전의 유효한 기준 곡선은 남깁니다. ‘모델 풀기’를 다시 누르거나 식을 변경하면 기준 해를 새로 선택합니다. 순수 수식 계산·선형 모드는 기존 동작을 유지합니다.

빈 구간은 **선택한 해의 추적이 완료되지 않은 구간**입니다. 이것만으로 실근 부재를 결론 내릴 수 없습니다. 근 병합·소멸, 정의역 이탈·분모 0, 수치 추적 실패를 지점 안내와 구간 검증으로 구분해야 합니다. 서로 다른 해를 선으로 연결하지 않습니다. 초기값 모드는 한 가지를 선택하므로 전체 비교에는 자동 탐색을 사용합니다.

## 화면과 리포트

- 병합 그래프 바로 위에 값 조절과 가로축 파라미터 선택을 배치했습니다. 세트를 삭제하지 않고 바꿀 수 있습니다. 값은 열린 시뮬레이션에 공통 적용됩니다.
- ‘설정 범위에서 발견한 가지’ 문구는 제거하고, 실제 의미·최대 6개 제한·추적 실패 해석은 접힌 도움말에 남겼습니다.
- 파라미터 변경과 비동기 응답 동안 창·전체화면 스크롤 위치를 유지합니다. 휠·터치·스크롤 키로 직접 이동하면 위치 고정을 즉시 해제합니다. 렌더링 갱신이 브라우저의 스크롤 앵커를 바꾸지 않게 했으며 포커스 복원에도 `preventScroll`을 적용했습니다.
- 리포트 각 카드에 ‘이 수치 읽는 법’을 넣었습니다. 계산 오차 상한, 마지막 보정량, 절대 증폭률, 구간 길이 검증률을 구분하고 단위·측정 오차·근 개수에 대한 해석을 설명합니다.
- 조건수의 상대 변화 진단과 절대 증폭률의 차이, 스칼라 조건수 1의 한계, ∞-norm과 2-norm 선택이 계산 정밀도를 높이는 설정이 아니라는 점을 펼쳐 확인할 수 있습니다.

자동 범위의 모든 실근 포획 확률은 이번 UI 수정으로 새로 도입하지 않았습니다. 첨부 엔진의 판정은 [2차 수정본 검토](UPLOADED_PATCH_V2_AUDIT.md), 남은 지원 범위는 [KNOWN_ISSUES.md](KNOWN_ISSUES.md)를 참고하세요.
