# 일반 등식 입력과 근 병합 안내

## 입력 방법

자동·수동 모드 모두 일반 등식을 입력합니다. 수식을 특별한 근 정의 함수로 감싸거나, 사용자가 좌변과 우변을 한쪽으로 옮겨 작성할 필요가 없습니다.

```text
x^2 = 4
```

자동 모드는 초기값 없이 여러 실수 해를 탐색합니다. 고급 수동 모드는 다음처럼 초기값 또는 범위를 추가해 한 해를 찾습니다.

```text
exp(x) = 2
x(0) = 1
```

```text
x^2 = 4
x(min) = 0
x(max) = 3
```

```text
x^2 + y^2 = 25
x - y = 1
x(0) = 3.8
y(0) = 2.8
```

번호 있는 함수 정의와 함수 간 연산도 같은 방식으로 사용합니다.

```text
f1(x) = 2x + 4
f2(x) = -3x + 7
f1(x) = f2(x)
```

함수 정의만 적으면 자동으로 ‘그 함수=0’을 가정하지 않습니다. `f1(x)=4` 또는 `f1(x)=0`처럼 풀 방정식을 추가합니다. `f1(x)=2x+4=0`의 정의·방정식 연쇄 표기도 계속 지원합니다.

에디터 힌트·예제·공식집·사용 안내에서 별도의 잔차식 입력 개념을 제거했습니다. 수치 결과의 기존 진단값은 **등식 오차(좌변−우변)**로 표시합니다. 계산 내부의 좌변·우변 차이 평가, 자동미분, 오차 검증은 수치 알고리즘에 필요한 연산으로 유지합니다.

## 기존 프로젝트

이전 근 정의 함수로 저장된 Nonlinear 프로젝트는 최초 로드·모드별 초안 복원·JSON 불러오기에서 일반 등식으로 전환합니다. 이전 보조식은 구문 트리로 전개하고, 원래 정의는 주석으로 남깁니다. 파라미터와 수식의 정의역을 바꾸거나 문자열을 코드로 실행하지 않습니다. 추론된 미지수 순서가 달라지면 선택한 해와 고정 시뮬레이션의 값 순서도 함께 맞춥니다.

해석할 수 없는 초안, 순환 참조, 과도한 전개는 자동 수정하지 않고 원본을 보존합니다. 계산 라이브러리 내부 표현과 이전 파일 호환 처리는 남아 있지만, 사용자가 그 표현을 작성할 필요는 없습니다. 일반 대입식만 계산하는 수동 모드의 명시식 계산도 유지합니다.

## 접점 메시지

| 확인한 현상                                               | 그래프의 안내    |
| --------------------------------------------------------- | ---------------- |
| 2차·4차의 짝수차 접점                                     | 근 병합          |
| 3차 변곡점 통과                                           | 변곡점 통과      |
| 정의역 경계의 접점                                        | 정의역 경계 도달 |
| 두 분기의 병합을 수치적으로 추정했으나 접점 검증은 미완료 | 근 병합 추정     |
| 수치 추적을 더 진행하지 못함                              | 추적 종료        |

버튼에는 현상 이름과 파라미터 좌표를 한 번만 표시합니다. 같은 설명을 제목과 본문으로 두 번 출력하지 않습니다. 3차 변곡점의 유일한 해를 두 근의 병합이라고 바꾸지 않습니다. 검증되지 않은 추적 실패도 해 소멸의 증명으로 바꾸지 않습니다.

반데르발스 예제의 각 가지는 같은 접점 앞에서도 서로 다른 위치에서 추적이 멈출 수 있습니다. 이전에는 이 **중단 위치**를 비교해 같은 접점이 두 메시지로 남거나 ‘추적 경계’로 표시됐습니다. 지금은 원래 식으로 검증한 **접점 좌표**를 대조하고, 두 가지의 수렴을 확인해 같은 병합 사건을 연결합니다. 그래프별 중복 제거도 같은 좌표 기준을 사용합니다. 환산 상태방정식과 단위 있는 몰체적 예제 모두 서로 다른 두 병합점을 각각 한 번 표시합니다.

이 변경은 이벤트 대조·표시에 적용합니다. 근 목록을 합치거나 기준 곡선 배열을 바꾸는 처리가 아닙니다. 현재 파라미터를 움직여도 기존 기준 곡선은 유지합니다.

## 첨부 코드 검토 결과

첨부 `nonlinear.ts`, `nonlinear_parser.ts`의 일반 등식 입력과 스칼라 초기값 지원 방향을 반영했습니다. 전체 파일을 교체하면 기존 자동미분, 비매끄러운 함수의 미분 없는 풀이, 입력 정규화·행 진단이 빠지므로 해당 부분은 보존했습니다.

연립식은 행마다 처음 나오는 미지수만 선택하지 않고 모든 방정식에서 미지수 순서를 함께 구성합니다. 초기값과 범위를 모두 입력한 스칼라 식은 이분법 실패 후 Newton 보정을 시도할 수 있지만, 최종 해가 지정 범위 밖이면 반환하지 않습니다. 범위를 한쪽만 입력하는 경우도 거부합니다. 변수 이름의 대소문자는 계속 구분합니다.

## 검증

- 전체 수치 회귀 검사 **463개**와 TypeScript·배포 빌드가 통과했습니다.
- 브라우저 68개 시나리오 중 전체 실행에서 67개가 통과했습니다. 나머지 한 건은 초기값도 허용하는 새 안내 문구에 맞춰 기대값을 수정한 뒤 재실행해 통과했습니다.
- 일반 등식·초기값·구간·함수 조합, 범위 밖 해 거부, 비매끄러운 스칼라 풀이, 저장 모델 전환과 해의 순서 보존을 회귀 검사로 확인합니다.
- Landau·환산 반데르발스·단위 있는 반데르발스의 두 병합점이 각각 한 사건으로 대조되는지 검사합니다. 서로 다른 작은 접점 좌표를 표시 자릿수만으로 합치지 않는 검사도 포함합니다.
- 브라우저에서 일반 등식 수동 입력, 도움말·보고서, 반데르발스 두 예제의 메시지 개수와 슬라이더 이동 시 기준 곡선 보존을 확인합니다.

다른 수치 알고리즘의 남은 문제는 [KNOWN_ISSUES.md](KNOWN_ISSUES.md)에서 관리합니다. 이번 UI·입력 변경으로 기존의 고차 접점 분류나 경로 인증 문제가 해결됐다고 표시하지 않습니다.
