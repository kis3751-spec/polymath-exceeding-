    다른 사람과 공유하는 방법

    Codespaces의 Ports 탭에서 실행 중인 5180 포트를 오른쪽 클릭하고 Port Visibility → Public을 선택하세요. 개인 Codespace의 Private 포트는 다른 사람이 자기 GitHub 계정으로 로그인해도 열리지 않을 수 있습니다. Public은 소개·로그인 화면에 도달하게 하는 설정이며, 계산기는 계속 IVC가 허용한 계정만 사용할 수 있습니다.

    연결 확인은 서버가 로그인 쿠키 없이 현재 주소의 소개 화면과 로그인 파일에 접속하는 검사입니다. 상대방 브라우저의 접속 경로까지 확인하는 것은 아닙니다. Codespace가 정지되거나 삭제되면 공유 주소도 멈춥니다. 계속 서비스하려면 상시 실행되는 HTTPS 서버에 배포해야 합니다.

    먼저 연결을 확인한 뒤 초대를 만들고 링크와 코드를 해당 사용자에게 직접 전달하세요. 이메일이 자동 발송되지는 않습니다. 상대방은 새 IVC 비밀번호를 정해야 하며, 관리자 비밀번호를 전달하면 안 됩니다.

    Admin Password는 현재 로그인한 최고 관리자 본인의 IVC 비밀번호입니다. 초대받는 사람의 비밀번호는 그 사람이 정합니다.

    48시간 안에 한 번 사용할 수 있습니다. 링크를 열면 초대받은 이메일이 표시됩니다. 링크가 로그인 화면에서 끊기면 Site address → Log in → Have an invitation code?에서 코드를 입력하세요. 링크·코드를 가진 사람이 해당 계정을 활성화할 수 있으므로 해당 사용자에게만 전달하세요. 다시 발급하면 이전 초대는 폐기됩니다.
